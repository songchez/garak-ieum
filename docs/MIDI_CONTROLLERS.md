# MIDI 컨트롤러 레인 (피치 벤드 · CC · 애프터터치 · 프로그램 체인지)

[MIDI 리전 벤치마크](MIDI_REGION_BENCHMARK.md) 2단계를 구현한 문서입니다. 음표 말고도 연주의 표정을 담는 MIDI 데이터, 곧 **피치 벤드**, **컨트롤 체인지(CC 0–127: 모듈레이션 휠, 볼륨, 팬, 익스프레션 …)**, **채널 애프터터치**, **프로그램 체인지**를 리전 안에 보관하고 편집·녹음·재생·가져오기/내보내기합니다. 서스테인 페달(CC64)은 같은 규칙을 먼저 구현한 사례이며 세부는 [SUSTAIN_PEDAL.md](SUSTAIN_PEDAL.md)에 있습니다.

## 다른 DAW는 어떻게 하나

| | Logic Pro | Ableton Live | 가락이음 |
| --- | --- | --- | --- |
| 저장 위치 | 리전 안의 MIDI 이벤트, 피아노롤 아래 MIDI Draw 레인 | 클립 엔벨로프 `MIDI Ctrl` | 리전의 컨트롤러 레인(`controllers`), 피아노롤 아래 레인 |
| 레인 추가 | 레인 메뉴에서 컨트롤러 선택 | 엔벨로프 선택 상자 | 머리글 **+ 레인** 메뉴 |
| 그리기 | 연필·직선·곡선, 점 선택·이동 | 연필·꺾은선 | 연필·직선·곡선·선택·지우개 |
| 피치 벤드 | 가운데로 되돌리기 | 가운데 0 | 더블 클릭으로 그 자리부터 가운데 |
| 재생 위치 이동 | Chase | 엔벨로프 값 재전송 | 리전 시작에서 값 이어받기(chase), 재생 시작·탐색·루프마다 재적용 |
| 녹음 | 연속값 감량(Thin) | 감량 | 녹음 때 자동 감량 |
| 파일 | CC·벤드 유지 | CC·벤드를 엔벨로프로 | 모두 유지, 내보내기에도 기록 |

## 사용법

### 레인 보기·추가

- MIDI 리전을 열면 데이터가 있는 컨트롤러 레인이 피아노롤의 VELOCITY 아래에 쌓여 보입니다. 맨 아래에는 기존 **SUSTAIN** 레인이 있습니다(이것도 레인 중 하나입니다).
- 머리글의 **+ 레인** 버튼: 피치 벤드, 모듈레이션(CC1), 익스프레션(CC11), 볼륨(CC7), 팬(CC10), 서스테인(CC64), 애프터터치, 프로그램 체인지, **CC 번호…**(0–127 전체, 이름이 있는 번호는 이름 표시). 체크된 항목을 다시 고르면 레인을 숨깁니다.
- 레인 왼쪽 위 **×**는 레인을 숨깁니다. 데이터는 지우지 않으며 **+ 레인**으로 다시 보입니다.
- 레인이 많으면 각 레인 높이가 60 px에서 30 px까지 줄어 음표 영역을 남깁니다. 편집기 패널을 키우면 다시 넓어집니다.
- 피치 벤드 레인의 **±2** 선택 상자는 이 리전의 벤드 범위(반음, 1–48)입니다. 내장 악기가 이 값을 씁니다(아래 "엔진별 동작").

### 그리기·편집

머리글의 **✎ 도구** 선택 상자(컨트롤러 레인이 있을 때 보임)로 도구를 고릅니다. 피아노롤 스냅 격자를 따르며 Ctrl을 누르면 격자를 무시합니다.

| 도구 | 동작 |
| --- | --- |
| 연필 | 드래그로 자유롭게 그립니다. 그린 구간의 기존 점은 바뀌고, 점은 자동으로 감량됩니다. 클릭 한 번은 점 하나 |
| 직선 | 드래그한 두 점 사이를 직선으로 채웁니다 |
| 곡선 | 두 점 사이를 곡선으로 채웁니다. Shift를 누르고 시작하면 반대 곡률 |
| 선택 | 점 클릭(Shift: 추가), 빈 곳 드래그로 사각형 선택, 선택한 점 드래그로 이동(Shift: 값만), Delete/Backspace로 삭제, Ctrl/⌘+A 전체 선택, Esc 해제 |
| 지우개 | 드래그한 구간의 점을 지웁니다 |

- **더블 클릭**: 그 위치에 기본값을 씁니다. 피치 벤드는 가운데(0)로 돌아오고, 모듈레이션·애프터터치는 0, 익스프레션은 127입니다. 선택 도구에서 점을 더블 클릭하면 그 점을 지웁니다.
- 피치 벤드는 가운데 근처에서 0에 붙습니다.
- 레인에는 악기가 실제로 듣는 계단 모양 곡선이 그려지고, 왼쪽 위에 재생 위치의 값(피치 벤드는 반음 환산)이 보입니다.
- 모든 편집은 실행 취소 한 단계입니다.

### 녹음·캡처

- MIDI 녹음([MIDI_RECORDING.md](MIDI_RECORDING.md))은 음표와 함께 피치 벤드, CC, 채널 애프터터치, 프로그램 체인지를 리전 레인으로 기록합니다. CC64는 서스테인 레인이 됩니다.
- 장치가 보내는 촘촘한 값은 **자동으로 감량**합니다(Logic의 Thin과 비슷). 같은 값은 버리고, 피치 벤드는 ±32(±2 범위에서 약 0.8센트), 7비트 값은 ±1 이상 바뀐 점만 남깁니다. 남는 점은 최대 1/128박마다 하나이고, 값이 크게 뛰면 바로 남깁니다. 마지막 값과 가운데(기본값)로 돌아온 점은 항상 남기므로 끝값은 정확합니다.
- 합치기 모드는 겹친 리전의 레인과 새 녹음을 합칩니다. 대체 모드는 녹음 구간을 새 녹음으로 바꿉니다. 사이클 녹음에서는 나중 회차가 같은 레인에서 자신이 기록한 구간을 덮어씁니다(음표는 모든 회차가 남음).
- 녹음 시작 전에 이미 움직여 둔 값(예: 모듈레이션 휠 위치)은 리전 첫 박에 들어갑니다.
- **캡처**도 마지막 연주 구간의 컨트롤러를 함께 리전으로 만듭니다.

### 가져오기·내보내기

- **파일 → 오디오·MIDI 가져오기…**: 서스테인 외의 CC, 피치 벤드, 채널 애프터터치를 레인으로 가져옵니다(이전 버전은 경고만 내고 버렸습니다). 같은 포트·채널의 컨트롤러는 그 채널의 모든 파트에 적용됩니다.
  - RPN 0(피치 벤드 범위)은 리전의 벤드 범위가 됩니다. 다른 RPN·NRPN 설정과 키별 애프터터치(Poly Pressure), SysEx는 가져오지 않고 안내합니다.
  - 첫 음표까지의 프로그램 체인지는 악기 지정으로 쓰이고, 그 뒤의 변경은 **프로그램 체인지** 레인이 됩니다.
  - Reset All Controllers(CC121)는 리셋형 레인(아래)을 기본값으로 돌립니다.
  - 기본값만 담긴 리셋형 레인(예: 처음에 한 번 보낸 가운데 피치 벤드)은 만들지 않습니다.
- **파일 → MIDI 내보내기…**: 레인을 CC·피치 벤드·채널 압력·프로그램 체인지 이벤트로 씁니다. 재생과 같게 리전 시작의 chase와 리전 끝의 리셋을 포함하고, 벤드 범위가 ±2가 아니면 리전 시작에 RPN 0을 씁니다. 가져오기 → 내보내기 → 가져오기를 하면 레인이 그대로 돌아옵니다(테스트로 확인).

## 동작 규칙

- **계단 값**: 이벤트는 그 박부터 다음 이벤트 전까지 값을 정합니다(같은 박의 마지막 값 우선). 직선·곡선은 촘촘한 계단으로 저장됩니다. 피치 벤드의 부드러움은 악기가 맡습니다(내장 악기는 약 4–5 ms로 매끄럽게 이어 줌).
- **리전 단위(서스테인과 같은 규칙)**: 레인은 리전의 원본 박 좌표에 저장되어 자르기·나누기·복제·합치기·루프에서 음표와 같이 움직입니다. 리전 왼쪽을 잘라내면 잘린 지점의 값을 리전 시작에서 이어받습니다(chase).
- **리셋형과 유지형**:
  - 리셋형(피치 벤드, 애프터터치, 모듈레이션 CC1, 브레스 CC2, 익스프레션 CC11)은 리전 끝과 루프 반복 경계마다 기본값(벤드 가운데, 0, 익스프레션 127)으로 돌아갑니다. 음표가 리전 끝에서 잘리는 것과 같습니다.
  - 유지형(볼륨 CC7, 팬 CC10, 프로그램, 그 밖의 CC)은 리전이 끝나도 값을 유지하고, 리전마다 시작에서 다시 보냅니다.
- **합치기**: 각 리전에서 실제로 들리던 레인만 남깁니다. 겹치지 않고 떨어진 리전은 앞 리전 끝에 리셋이 들어갑니다.
- **트랜스포즈·퀀타이즈**는 레인에 영향을 주지 않습니다. 트랙·리전 딜레이는 음표와 함께 레인도 옮깁니다.
- 같은 위치에서는 리전 끝 리셋 → 다음 리전의 chase → 컨트롤러 → 노트 오프 → 노트 온 순서입니다.

## 엔진별 동작

| 컨트롤러 | 내장 신스·샘플러 (Web Audio·네이티브 같음) | 이음웨이브 (네이티브) | VST3 (네이티브) |
| --- | --- | --- | --- |
| 피치 벤드 | 리전 벤드 범위(기본 ±2)로 음 높이 변화, 약 5 ms로 매끄럽게. 드럼 킷은 무시 | 패치의 피치 벤드 범위 사용(리전 범위는 쓰지 않음) | 샘플 단위로 전달(`IMidiMapping` `kPitchBend`) |
| 모듈레이션(CC1) | 비브라토 5.5 Hz, 127에서 ±50센트 | 매크로 1(패치가 매크로 1을 라우팅했을 때만 효과) | 샘플 단위로 전달 |
| 애프터터치 | 비브라토 깊이 = 모듈레이션과 애프터터치 중 큰 값 | 매크로 2 | `kAfterTouch`로 전달 |
| 볼륨(CC7)·익스프레션(CC11) | 게인 = (CC7/100)² × (CC11/127)². CC7 100이 원래 크기 | 출력 게인(같은 곡선, 약 5 ms 부드럽게) | 전달 |
| 팬(CC10)·그 밖의 CC | 효과 없음 | 효과 없음 | 플러그인이 `IMidiMapping`으로 연결한 파라미터로 전달 |
| 프로그램 체인지 | 효과 없음 | 효과 없음 | 플러그인이 `kCtrlProgramChange`(130)를 연결했을 때만 |

- VST3에는 MIDI CC 이벤트가 없어 모든 컨트롤러가 플러그인의 `IMidiMapping`이 정한 파라미터의 샘플 단위 포인트로 들어갑니다. 연결하지 않은 컨트롤러는 플러그인이 받지 않습니다.
- **재생 시작·탐색**: 그 위치에서 유효한 값을 먼저 적용합니다(chase). 레인에 있는 리셋형 컨트롤러는 앞선 이벤트가 없으면 기본값을 보냅니다. **정지**하면 리셋형만 기본값으로 돌리고 볼륨·팬·프로그램은 유지합니다. 내장 악기는 정지 때 모두 기본값(벤드 범위 ±2 포함)으로 돌아갑니다.
- **실시간 입력**: MIDI 키보드의 피치 벤드 휠·모듈레이션 휠·익스프레션 페달·애프터터치가 녹음하지 않아도 바로 소리에 반영됩니다. 웹은 JavaScript가, 데스크톱은 호스트 오디오 스레드가 처리합니다. 실시간 입력의 벤드 범위는 마지막으로 재생한 리전 범위(정지 후에는 ±2)입니다. 트랙을 바꾸면 이전 트랙의 벤드는 가운데로 돌아가고, 패닉(모든 음 끄기)은 벤드 가운데·모듈레이션 0으로 돌립니다.

## 저장 형식

프로젝트 스키마 **16**에서 추가되었습니다(스키마 14·15는 다른 기능이 쓰며 1–16을 모두 엽니다).

```jsonc
"controllers": {
  "pitchBend": [{ "beat": 0, "value": -8192 }, { "beat": 1.5, "value": 0 }],   // −8192…8191, 0 = 가운데
  "cc1": [{ "beat": 2, "value": 64 }],                                       // 'cc0'…'cc127' (cc64 제외), 0…127
  "aftertouch": [{ "beat": 3, "value": 20 }],                                // 0…127
  "program": [{ "beat": 0, "value": 5 }]                                     // 0…127
},
"bendRange": 12                                                             // 0…48 반음, 없으면 2
```

- `beat`는 음표 `start`와 같은 원본 박 좌표, 레인마다 박 순서대로 하나씩만 있어야 합니다. 레인당 최대 200,000개.
- **서스테인은 마이그레이션하지 않았습니다.** CC64는 노트 오프를 미루는 특별한 의미가 있어 기존 `MidiClip.sustain`(스키마 13)에 그대로 두고, `controllers`에는 `cc64`를 넣을 수 없습니다. 피아노롤에서는 SUSTAIN 레인이 다른 레인과 같은 목록에 있고, 녹음·가져오기·내보내기는 CC64를 `sustain`으로 보냅니다. 따라서 스키마 13 파일은 바뀌지 않고 열리며, 스키마 15 이하 파일에 `controllers`나 `bendRange`가 있으면 거부합니다.
- 네이티브 타임라인: 트랙의 `controls: [{frame, controller, value}]`(최대 100,000개). `controller` 0–127 CC, 128 채널 애프터터치, 129 피치 벤드(−8192…8191), 130 프로그램 체인지, 131 벤드 범위(반음, 내장 악기 전용). VST3는 CC64를 포함한 전부, 이음웨이브는 CC64·131을 뺀 전부, 내장 악기는 CC64·130을 뺀 전부와 131을 받습니다(페달은 노트 오프 위치에 이미 반영). 실시간 명령 `note.control`도 같은 번호와 값 범위를 받습니다.

브라우저 확인(Chrome, Web Audio): 벤드와 모듈레이션이 든 MIDI 파일을 가져와 WAV로 렌더하면 +8191 구간이 +200.1센트, 연필로 그린 −8192 구간이 −199.8센트, 더블 클릭 뒤 원래 음높이로 돌아오고, 모듈레이션 127 구간의 50 ms 주파수 흔들림이 1.1 Hz → 13.5 Hz로 커지며, 익스프레션 직선을 0까지 그리면 소리가 사라졌습니다. 내보낸 MIDI에는 피치 벤드 −8192, 0, 8191, 0이 기록됩니다.
