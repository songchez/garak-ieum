# 리전 게인 · 페이드 · 크로스페이드

오디오 리전마다 볼륨(게인)과 페이드 인/아웃, 크로스페이드를 둡니다. 아래 벤치마크를 바탕으로
설계했고, Web Audio 엔진과 네이티브(C++) 엔진, WAV 내보내기가 같은 엔벨로프를 씁니다.

## 1. 벤치마크 요약

`[U]`는 공식 매뉴얼에서 직접 확인하지 못한 항목입니다.

| | 리전 게인 | 페이드 | 크로스페이드 | 노멀라이즈 |
|---|---|---|---|---|
| Ableton Live 12 | 클립 뷰 Gain 슬라이더(dB). 여러 클립을 고르면 값의 범위를 표시 | 클립 가장자리의 작은 사각 핸들 + 곡선 핸들. "Create Fades on Clip Edges"가 켜져 있으면 기본 4 ms | 페이드 핸들을 옆 클립 너머로 끌거나 Create Crossfade. 붙은 클립은 자동 4 ms | 클립 노멀라이즈 없음(내보내기만) [U] |
| Logic Pro 11 | 리전 인스펙터 Gain −30…+30 dB, Gain 도구 | 인스펙터 Fade In/Out + Curve, Fade 도구. 유형 Out / X / EqP / X S | Fade 도구로 직접, 또는 **Drag 메뉴 "X-Fade"**로 겹치면 자동 | Normalize Region Gain(비파괴, 리전 게인에 기록) |
| Pro Tools | 클립 게인 라인 + 좌하단 페이더 아이콘, 약 −∞…+36 dB | Smart Tool로 위 모서리 드래그, Fades 대화상자(곡선 프리셋) | Fades / **Batch Fades**. Link: Equal Power / Equal Gain. 클립 바깥 오디오(핸들) 사용 | 클립 게인 노멀라이즈는 기본 기능 아님 [U] |
| Reaper 7 | 아이템 위 가장자리를 아래로 끌기, F2에서 부스트 | 아이템 **위쪽 양 모서리** 핸들, 우클릭으로 모양 선택, 기본 약 10 ms 자동 페이드 | 겹치면 자동 크로스페이드(토글) | Normalize items: Peak / RMS / LUFS |
| Cubase 13/14 | 이벤트 **위 가운데 사각 핸들**, 파형이 볼륨을 따라 다시 그려짐 | 위쪽 양 모서리 삼각 핸들, 더블 클릭 시 Fade 대화상자 | Crossfade 명령, Auto Fades 대화상자, Equal Power / Equal Gain | Direct Offline Processing Normalize |
| Studio One 6/7 | 위 가운데 사각 핸들, 인스펙터 Gain −40…+24 dB | 위쪽 모서리 핸들, 가운데 점을 끌어 곡선 조절 | 겹친 범위 선택 후 X | 인스펙터 Normalize(0 dBFS) |

공통점은 다음과 같습니다.

- 게인은 **리전 위에서 직접 끄는 핸들(선)**과 인스펙터 숫자 필드를 함께 둔다. 파형이 게인에 맞게 다시 그려진다.
- 페이드는 **리전 위쪽 양 모서리 핸들**을 가로로 끈다. 곡선은 우클릭 메뉴나 인스펙터에서 고른다.
- 크로스페이드에는 두 방식이 있다. 명시적 명령(Ableton, Pro Tools, Cubase, Studio One)과 겹치면 자동(Logic X-Fade, Reaper)이다.
  같은 테이크를 이어 붙인 편집에는 Equal Gain(직선), 다른 소리끼리는 Equal Power를 쓰는 것이 원칙이다(Pro Tools Link 옵션).
- 여러 리전을 고르면 게인과 페이드가 모두에 적용된다.

## 2. 설계

### 데이터 (프로젝트 스키마 10)

`AudioClip`의 값은 다음과 같습니다.

| 필드 | 의미 |
|---|---|
| `gain` | 선형 배율. 오디오 0…10^(24/20)(+24 dB). MIDI 리전은 벨로시티 배율이므로 그대로 0…2 |
| `fadeIn`, `fadeOut` | 리전의 들리는 구간(트림 후) 기준 초. 둘의 합이 리전보다 길면 비율대로 줄인다(`fadeLengths`) |
| `fadeInCurve`, `fadeOutCurve` | `linear`(기본, 필드 생략) · `equalPower` · `sCurve` · `exponential` · `logarithmic` |

- 스키마 9 이하 파일은 그대로 열립니다. 곡선이 없으면 직선 페이드이고, 게인과 페이드 값은 바뀌지 않습니다.
- 곡선 필드나 +6 dB를 넘는 오디오 게인은 스키마 10에서만 허용합니다. 예전 앱은 스키마 10 파일을 열지 않고 "지원하지 않는 버전"이라고 알립니다.
- 직선 곡선은 필드를 생략해서 저장하므로, 바꾸지 않은 리전은 예전과 같은 JSON으로 저장됩니다.

### 곡선 (진행도 x: 0 = 무음 끝, 1 = 원래 레벨)

| 곡선 | 식 | 쓰임 |
|---|---|---|
| 직선 | x | 기본값, 같은 소리를 이어 붙인 크로스페이드 |
| 등전력 | sin(x·π/2) | 서로 다른 소리의 크로스페이드(in² + out² = 1) |
| S 곡선 | (1 − cos πx)/2 | 부드러운 시작과 끝 |
| 지수 | x² | 천천히 올라오는 페이드 인, 끝이 빨리 사라지는 페이드 아웃 |
| 로그 | 1 − (1 − x)² | 빨리 올라오는 페이드 인 |

엔벨로프는 `gain × min(fadeIn(x), fadeOut(x))`입니다. 공용 구현은 `src/core/clipEnvelope.ts`의
`fadeShape`, `fadeLengths`, `envelopeAt`이고, 네이티브는 `native/include/garak/engine.hpp`의 `fadeShape`입니다.
두 구현은 테스트로 같은 값을 확인합니다.

### 크로스페이드

재생 규칙(V-09)은 "뒤에 시작하는 리전이 앞 리전을 자른다"입니다. 여기에 한 가지를 더했습니다.
**뒤 리전의 페이드 인이 끝날 때까지 앞 리전이 계속 들립니다**(`audioWindows(track, end, bpm)`).
따라서 크로스페이드는 "앞 리전 fadeOut = 겹친 길이, 뒤 리전 fadeIn = 겹친 길이"만으로 표현되고,
별도 객체가 필요 없습니다(Reaper와 같은 방식).

- **크로스페이드 만들기**(리전 우클릭): 같은 트랙에서 고른 오디오 리전 중 겹치거나 붙어 있는 쌍마다 만든다.
  붙어만 있으면 양쪽 원본 여유분(핸들)으로 최대 25 ms까지 서로 늘려 겹치게 한다(Ableton, Pro Tools 편집 크로스페이드).
  핸들이 한쪽에만 있으면 그쪽이 전부 늘어난다. 두 리전이 같은 파일의 연속 구간이면(분할 편집) 직선을, 아니면 등전력을 쓴다.
- **Drag: 크로스페이드** 모드(Logic X-Fade): 리전을 옮기거나 길이를 바꿔 다른 오디오 리전과 일부만 겹치면 그 구간이 자동으로 크로스페이드된다.
  한 리전이 다른 리전을 완전히 덮거나 MIDI 리전이면 "겹치지 않음"처럼 자른다.
- 기본 드래그 모드("겹치지 않음")는 그대로 두었습니다. 자동 크로스페이드는 사용자가 고를 때만 켜집니다.

### 엔진

- **Web Audio**(`src/audio/graph.ts`): 리전마다 GainNode 하나를 둔다. 곡선 페이드는 32개 직선 구간의
  `linearRampToValueAtTime`으로 근사한다(오차 < 0.05 dB). `setValueCurveAtTime`은 다른 이벤트와 겹치면 예외를 내므로 쓰지 않았다.
  같은 그래프를 OfflineAudioContext로 돌려 WAV를 내보내므로 내보내기에도 그대로 적용된다.
- **네이티브**(`native/src/engine.cpp`): 오디오 창마다 샘플 단위로 `gain × fadeShape(...)`를 계산한다.
  `fadeInCurve` / `fadeOutCurve`(0…4)를 프로토콜로 받는다. 값이 없으면 직선이라 예전 호스트 메시지도 그대로 동작한다.
  게인 검사 범위는 0…16이다.
- 워프와 피치 편집은 오프라인으로 새 음원을 렌더하므로, 게인과 페이드는 그 결과 위에 재생 시점에 적용된다.

## 3. 사용법

1. **게인**: 오디오 리전 위에 마우스를 올리면 파형 위에 가로선이 보인다. 위아래로 끌면 dB가 바뀌고 값이 표시된다.
   - Shift를 누르고 끌면 10배 세밀하게 바뀐다. 더블 클릭하면 0 dB로 돌아간다.
   - 0 dB가 아닐 때 선은 황동색으로 계속 보이고, 파형도 게인만큼 커지거나 작아진다.
2. **페이드**: 리전 파형 영역 위쪽 양 모서리의 작은 사각 핸들을 가로로 끈다.
   - Shift를 누르면 세밀하게, 더블 클릭하면 페이드가 없어진다. 페이드 모양은 파형 위에 곡선으로 그려진다.
3. **곡선**: 리전 우클릭 → 페이드 인 곡선 / 페이드 아웃 곡선. 인스펙터의 "인 곡선 / 아웃 곡선"에서도 고를 수 있다.
4. **숫자 입력**: 인스펙터 리전 섹션의 게인(−∞…+24 dB), 페이드 인/아웃(ms 또는 s 입력)을 쓴다.
5. **크로스페이드**: 붙어 있거나 겹친 두 리전을 Shift 클릭으로 고르고 우클릭 → 크로스페이드 만들기.
   Drag 메뉴를 "크로스페이드"로 두면 겹치게 옮길 때마다 자동으로 만들어진다.
6. **노멀라이즈**: 우클릭 → 노멀라이즈(−0.1 dBFS 피크). 원본은 바꾸지 않고, 보이는 구간의 피크가 −0.1 dBFS가 되도록 리전 게인만 정한다(Logic 방식).
7. **여러 리전**: 선택한 리전에 핸들 조작, 메뉴, 인스펙터가 모두 적용된다. 게인은 각 리전 값에 같은 dB만큼 더하고, 페이드는 같은 길이로 맞춘다.
   한 번 끈 동작은 실행 취소 한 번으로 되돌아가고, 끄는 도중 Esc를 누르면 취소된다.

## 4. 남은 일

- 리전 안의 게인 엔벨로프(Pro Tools 클립 게인 라인 브레이크포인트, Studio One Clip Gain Curve)는 아직 없다.
- 크로스페이드 곡선을 끌어서 비대칭으로 바꾸는 기능, 크로스페이드 위치를 Shift+드래그로 옮기는 기능(Reaper)은 아직 없다.
- 루프 반복 구간에서는 페이드를 보여 주기만 하고, 핸들은 원본 리전에만 있다.
- LUFS/RMS 노멀라이즈와 사용자 지정 목표 레벨은 아직 없다.
