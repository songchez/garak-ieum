# 시김새 그래픽 편집기

노브만이 아니라 그래프·노드·숫자 입력으로 시김새를 조절하는 화면들의 설계 메모입니다. 그룹별로 섹션을 나눕니다.

## EQ·필터

대상: `eq`(Curve 8, 파라메트릭 EQ)와 `filter`(Sweep). 코드: `src/components/sigimsae/eq/`, 모델 `src/devices/effects/eqModel.ts`, 커널 `rust/garak-dsp/src/fx/eq.rs`(이전 네이티브 `eq_effects.inc`는 0.3.3에서 삭제).

### 화면 요소 요약

| 요소 | 가락이음 동작 |
| --- | --- |
| 커브 직접 편집 | 노드 드래그, 더블클릭 추가, 휠 Q/기울기, Alt+클릭 바이패스, 우클릭 메뉴, 분석기, 선택·호버 밴드 채움, 음이름 토글, 범위 ±6/12/24 |
| 밴드 슬롯 | 8밴드 슬롯 + 색 칩, 카드 안 미니 커브 직접 편집, 확대 편집기 |
| 밴드 색·숫자 행 | 밴드별 단청 계열 색, 선택 밴드 숫자 필드(주파수/게인/Q/기울기) |
| 숫자 입력 | 숫자 필드에 "1.2k" 입력, ↑/↓ 단계, Shift 미세, 방향키로 노드 이동 |

### 동작

- **Curve 8 (EQ)** — 8밴드. 모양: 로우 컷, 로우 셸프, 벨, 노치, 하이 셸프, 하이 컷. 컷은 12/24/36/48 dB/oct(버터워스 단 구성, Q 0.71 = 평탄, 높이면 공진). 출력 게인 ±24 dB.
  - 저장 호환: 예전 3밴드의 `low`/`mid`/`midFreq`/`high`가 그대로 밴드 1–3의 게인/주파수입니다. 밴드 1–3 기본값이 예전 고정 음색(220 Hz 로우 셸프, Q 0.9 벨, 4.5 kHz 하이 셸프)이라 옛 프로젝트와 라이브러리 변형이 똑같이 들립니다(네이티브 테스트가 비트 단위로 확인). 밴드 4–8은 꺼진 채 시작합니다.
  - 셸프는 Web Audio `BiquadFilterNode` 제약(셸프 Q 없음, S = 1)을 따라 기울기가 고정입니다.
- **Sweep (필터)** — 노드 좌우 = 컷오프, 위아래 = 레조넌스, 휠 = 기울기(12/24/48). 12 dB/oct는 예전 단일 필터와 같고, 24/48은 기본 레조넌스 0.7에서 평탄합니다.

### 조작

| 동작 | 결과 |
| --- | --- |
| 노드 드래그 | 주파수 + 게인(컷·노치는 위아래 = Q). 한 번의 드래그 = 실행 취소 한 단계 |
| Shift + 드래그 / Shift + 키 | 미세 조절 |

| 빈 곳 더블클릭 | 그 위치에 밴드 추가(30 Hz 아래 로우 컷, 15 kHz 위 하이 컷, 나머지 벨) |
| 노드 더블클릭 / Home | 게인 0 dB(컷은 Q 초기화) |

| 카드의 확대 버튼 | 큰 편집기(모달). Esc로 닫고 포커스는 버튼으로 돌아감, Tab은 안에서 순환 |

### 분석기

웹에서는 편집기가 장치의 탭을 조회하면 엔진이 그 EQ·필터 뒤 신호를 분석 탭으로 보내고(`src/devices/effects/analysis.ts`, `src/audio/engineAnalyser.ts`: AnalyserNode와 같은 FFT 4096·Blackman 창·평활 0.72·dB), 화면은 4.5 dB/oct 기울임과 피크 홀드로 차분하게, 30 fps로 React 렌더 없이 SVG 경로만 바꿔 그립니다. 유틸리티의 스테레오 스코프도 같은 탭의 좌우 1024프레임을 읽습니다. 데스크톱 엔진은 아직 스펙트럼을 보내지 않아 "분석기: 데스크톱 엔진은 아직 스펙트럼을 보내지 않습니다"를 보입니다.

### 공통 상호작용 규칙

- 카드 = 그래프 + 핵심 노브. 그래프 더블 클릭 또는 ⤢ 버튼 → 큰 편집기(어두운 모달, Esc 닫기, 포커스 가둠, 닫으면 원래 버튼으로 포커스 복귀).
- 모든 드래그는 한 번의 실행 취소 단위(history gesture). 드래그 중 Esc = 원래 값으로 되돌리고 취소. Shift = 미세(1/5 속도). 손잡이 더블 클릭 = 그 손잡이의 기본값.
- 손잡이·XY 패드·대역 모서리는 `role="slider"` + 방향키(좌우 = X 파라미터, 위아래 = Y, PageUp/Down = 크게, Shift = 미세). 칩은 radiogroup + 방향키.
- 노브는 그대로 남겨 숫자 정밀 조절(카드 4개 안팎, 큰 편집기는 전부).
- 그림은 DSP를 그대로 따른다: `space/math.ts`가 이펙트 수식(처음에는 kernels.ts / reverb.ts / drive.ts, 0.3.3부터 DSP는 Rust 커널 `rust/garak-dsp`뿐)을 미러링하고 단위 테스트(`math.test.ts`)로 고정.

### 성능

- 애니메이션은 requestAnimationFrame에서 ref로 DOM 속성만 갱신(React 렌더 없음), 미리 할당한 배열 사용. 화면 밖(IntersectionObserver), 탭 숨김, 꺼진(bypass) 장치, `prefers-reduced-motion`에서는 멈추고 정지 화면 1장만 그림.
- 오디오 코드는 손대지 않음. 유틸리티 고니오미터는 고정 테스트 신호(상관도 0.6)를 설정에 통과시킨 미리보기이고, 재생 중에는 `engine.getTrackLevel()`로 크기만 숨 쉼 → 네이티브 엔진에서도 동일하게 동작.

### 남은 일

- 실제 신호 고니오미터/스펙트럼: 엔진(웹 워크릿·네이티브)에 장치별 분석 스트림 API가 생기면 테스트 신호 대신 연결(0.3.3부터 웹도 Web Audio 분석 탭이 없음).
- 리버브 초기 반사(early reflections) 표시, 딜레이 테이프 와우/플러터 흔들림 표시.
- 테이프 온기(로우패스+저역 범프)는 전달 곡선에 안 보임 → 작은 톤 곡선 추가 여지.

### 설계

- **카드(랙)**: 116 px 정사각 전달 곡선 + 실시간 입력 점(입력 → 실제 출력 위치) + 세로 GR 미터(피크 홀드) + 그래프로 다루지 않는 파라미터 노브(어택·릴리즈·메이크업 / 릴리즈 / 어택·홀드·릴리즈). 칩에 스레숄드·비율(실링·입력) 값. 확장 버튼 또는 곡선 더블클릭 → 큰 편집기.
- **조작**: 컴프 — 꺾이는 점 좌우 = 스레숄드, 그 오른쪽 아무 곳 세로 = 비율. 리미터 — 꺾이는 점 상하 = 실링, 좌우 = 입력 게인(곡선이 옆으로 이동). 게이트 — 꺾이는 점 좌우 = 스레숄드. 공통: Shift = 미세, Alt+클릭 = 기본값, 드래그 한 번 = 실행 취소 한 단계, 손잡이는 `role=slider`로 화살표(±1 dB, Shift ±0.1, PageUp/Down ±6, Home/End).
- **큰 편집기**: 기타 앰프 창과 같은 어두운 대화상자(Esc 닫기, 포커스 가둠, 닫으면 원래 버튼으로 포커스 복귀). 전달 곡선 · 스크롤 기록 · 큰 GR 미터 · (76) VU 바늘 · (게이트) 엔벨로프 · 모든 파라미터 노브와 숫자 칸.
- **곡선 수식**은 DSP와 같음: 컴프는 네이티브 `Compressor`의 6 dB 소프트 니(`kneeOver`), 리미터는 `min(입력+게인, 실링)`, 게이트는 4 dB 히스테리시스(`curve.ts`, 단위 테스트).
- **실시간 계량**: 엔진이 장치별로 `input`(검출기 피크, 선형)과 `gain`(가장 낮은 적용 게인, 선형, 메이크업 제외)을 냄.
  - 웹: 엔진 워크릿이 `take_dynamics` 값을 미터 블록(SAB seqlock, 없으면 상태 메시지)에 게시하고 `WebAudioEngine.getDeviceMeter`가 인서트 id로 읽음([RUST_ENGINE 5.7](RUST_ENGINE.md#57-웹-호스트-2차-엔진-안에서-끝나는-일)). 이전 Web Audio 경로(`DynamicsCompressorNode.reduction`, 공용 워클릿 `port.postMessage`)는 0.3.3에서 삭제.
  - 네이티브: `StereoProcessor::dynamics()`의 `DynamicsTap`(원자값, 콜백 무할당) → 콜백 끝 `publishDynamics`가 25~50 ms 2-버킷 창으로 모아 `EngineSnapshot::dynamics` → 호스트 상태 JSON `dynamics[deviceId]` → `NativeAudioEngine.getDeviceMeter`. 기존 25 Hz 상태 폴링을 그대로 탐.
  - 화면은 rAF에서 ref에 직접 그림(React 재렌더 없음), 탭이 숨으면 멈춤. 엔진이 값을 안 주면 정적 곡선만 보이고 점·미터는 쉼.

### 남은 일

- 웹 컴프는 브라우저 `DynamicsCompressorNode`라 무릎 모양이 네이티브와 조금 다름(곡선은 네이티브 기준).
- 사이드체인·룩어헤드·자동 메이크업은 파라미터가 없어 표시하지 않음.
- 기록 해상도는 60 프레임/초(웹 리미터·게이트는 30 Hz 갱신).
