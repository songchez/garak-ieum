# 시김새 (이펙트) 목록

가락이음에서는 트랙 이펙트를 **시김새**라고 부릅니다. 시김새는 두 층으로 나뉩니다.

- **모듈**: 실제로 소리를 처리하는 일반 이펙트입니다. 저장 파일에는 모듈 id(`delay`, `reverb` …)와 숫자 파라미터만 남습니다.
- **변형(variant)**: 같은 모듈에 노브 값 묶음(프리셋)과 고유한 이름·용도 라벨을 붙인 라이브러리 항목입니다. 고르면 그 값으로 모듈이 추가되고 헤더에 변형 이름이 표시됩니다. 추가한 뒤에도 노브는 모두 바꿀 수 있고, 헤더 이름을 더블 클릭하면 이름을 바꿀 수 있습니다(빈 이름이면 모듈 이름으로 돌아감).

정의 위치

| 내용 | 파일 |
| --- | --- |
| 모듈 파라미터(웹) | `src/devices/effects/*.ts`, `src/devices/effects/sigimsaeDefs.ts` |
| 샘플 처리 커널(웹 워클릿) | `src/devices/effects/kernels.ts`, `src/devices/effects/sigimsae.worklet.ts` |
| 네이티브 DSP | `native/src/dsp.cpp`, `native/src/sigimsae_effects.inc` (커널과 클래스 단위로 맞춤) |
| 라이브러리 변형 | `src/core/sigimsaeVariants.ts` |

이름 규칙: 한국적인 이름과 장난스러운 서양식 오마주 이름을 섞되 실제 상표·모델명은 쓰지 않습니다.

| `limiter` | Ceiling | 리미터 | 다이내믹 | 입력 0 dB, 실링 −1 dB, 릴리즈 100 ms | 지연 없는 피크 리미터: 즉시 어택, 지수 릴리즈, 실링 하드 보장(트루 피크 아님) |

| `tape` | Reel 15 | 테이프 새츄레이션 | 드라이브·앰프 | 드라이브 6 dB, 온기 50 %, 믹스 100 %, 출력 0 dB | 비대칭 tanh(바이어스 0.15), 110 Hz 헤드 범프(온기×3 dB), 온기로 고역 롤오프(20→5 kHz), DC 차단 |

| `utility` | Width | 유틸리티 | 유틸리티 | 게인 0 dB, 팬 0, 폭 100 %(0–200 %), 모노 끔, 위상 반전(끔/왼/오른/양쪽) | 위상 → M/S 폭(모노는 폭 0 = 정확한 L/R 평균) → 밸런스 팬 → 게인 |

공통 동작

- 바이패스(전원 끔)는 엔진이 그 시김새를 아예 건너뛰므로 비트 단위로 원음과 같습니다(네이티브 테스트로 확인).
- 노브를 돌리면 값이 약 12 ms에 걸쳐 부드럽게 바뀝니다(웹 워클릿과 네이티브 동일).
- 딜레이·리버브·플랜저·게이트·리미터는 내보내기 꼬리 길이를 계산해 잔향이 잘리지 않게 합니다.
- 웹 엔진에서 딜레이와 새 모듈 9종은 하나의 오디오 워클릿(`garak-sigimsae-v1`)으로 처리하고, 처음 만들 때 저장된 값을 함께 넘겨 오프라인 내보내기도 첫 샘플부터 같은 설정으로 시작합니다.
- 저장 형식: 새 모듈 id와 기기 이름(`name`, 선택)은 추가 필드라 스키마 버전을 올리지 않았습니다. 예전 프로젝트의 딜레이·리버브는 새 파라미터가 기본값으로 채워져 그대로 열립니다. 새 모듈이나 새 딜레이 박자(셋잇단·1/16. 등)가 들어간 파일을 이전 버전 앱에서 열면 "unknown effect type"/옵션 오류로 열기를 거부합니다(소리가 조용히 바뀌지 않음). 이전 앱은 모르는 파라미터(로우컷·테이프·공간 등)와 이름은 무시하고 엽니다.
