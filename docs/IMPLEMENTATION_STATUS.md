# 상호작용 설계와 현재 코드의 상태

2026-10-31 · 개발 스냅샷 · 정식 1.0 아님

## 현재 작업본의 위치와 범위

이 작업본은 대화에 연결된 클라우드 개발 공간에서 만들었습니다. 사용자 컴퓨터에 직접 설치하거나 사용자 GitHub 저장소에 연결한 상태가 아닙니다. 내려받은 소스 폴더에서 README의 명령으로 로컬 개발을 시작할 수 있습니다. 제품명은 가락이음으로 확정했습니다. 삼태극 북·멀티트랙 로고와 덕온공주체 이름을 별도 요소로 적용했습니다.

승인된 Logic 참고 화면 배치 시안과 현재 실행 가능한 React 프로토타입은 별개입니다. 이번 변경은 단축키·상호작용 상세 명세 작성과 기존 입력 처리의 오류 수정입니다. 승인된 모든 패널 배치와 아래 명세 전체를 구현했다고 표시하지 않습니다.

## 브랜드 적용

확정된 로고와 별도 이름을 앱 상단·소개 창에 적용했습니다. 이름은 덕온공주체의 고정된 네 글자로 조판한 SVG(10,033바이트)를 사용합니다. 전체 TTF(7,946,740바이트)는 소스와 배포 자산에서 제외했습니다. 브라우저에서 두 위치의 이름 표시와 출처 링크를 확인했습니다.

| 영역 | 실제 변경 |
|---|---|
| 데이터 모델 | `ClipBase.mute?: boolean`를 추가했습니다. 검증은 선택적 boolean으로 하며, 값이 없으면 저장하지 않습니다. 엔진 `scheduleRange`는 뮤트된 클립을 예약하지 않습니다. |

| 클릭/더블 클릭 | 클립 클릭은 하단 탭을 바꾸지 않고, 더블 클릭은 편집기를 엽니다. 헤더 클릭은 트랙과 그 클립 전체를 선택합니다. 헤더 더블 클릭이나 새 플러그 버튼은 디바이스를 엽니다. |
| 드래그 | 선택한 모든 클립이 함께 이동합니다. 같은 종류 트랙으로 세로 이동합니다. Alt=복사, Ctrl=세밀하게, Ctrl+Shift=스냅 무시, Shift=축 고정입니다. 가장자리에서는 자동 스크롤하고, 복사 중에는 원래 위치를 점선으로 표시합니다. |
| 트림 | 왼쪽 경계 핸들을 추가했습니다. 오디오는 비파괴(원본 오프셋), MIDI는 음표 이동·자르기입니다. 오른쪽 경계와 함께 여러 클립에 같은 양을 적용합니다. |
| 눈금자·확대 | 위쪽 띠에서 반복 구간 만들기·이동·경계 조절·켜기/끄기를 합니다. 재생 위치 이동은 스냅을 따르고 Shift는 스냅을 무시합니다. 재생 위치 따라가기 토글을 추가했습니다(기본 켬). 확대/축소는 아래 '영역별 확대/축소'를 봅니다. |
| 영역별 확대/축소 | 어레인지먼트(박자 폭·트랙 높이), 피아노롤(박자 폭·건반 높이), 믹서(채널 폭·페이더 높이), 디바이스 랙(카드 배율), 브라우저(촘촘/넉넉)가 각자 배율을 가집니다. `⌘/Ctrl+←/→` 가로, `⌘/Ctrl+↑/↓` 세로, `Z` 맞춤은 키 포커스 영역(`data-keyboard-scope`: timeline·piano·mixer·devices, 없으면 어레인지먼트)에 적용합니다. `Ctrl/⌘+휠`(핀치) 가로, `Ctrl/⌘+Shift+휠`·`Alt+휠` 세로는 포인터 위치를 고정합니다. 순수 계산은 `core/zoom.ts`, 휠 처리는 `useZoomWheel`, 상태는 App의 `zoom` 객체이며 `localStorage['garak-ieum:zoom']`에 보관합니다. 트랙 높이는 CSS 변수 `--row-h`로 클립·미리보기 높이를 계산합니다. |
| 메뉴 | 클립·트랙 헤더·빈 레인 우클릭 메뉴를 추가했습니다(`ContextMenu`). 트랙 색상은 하위 메뉴입니다. |
| 트랙 | 번호를 드래그해 순서를 바꾸고(삽입선 표시) 이름은 그 자리에서 바꿉니다. 복제와 위/아래 이동을 추가했습니다. 트랙 삭제는 항상 확인 창을 거칩니다. 휴지통 버튼에서 클립 선택이 없을 때 조용히 삭제되던 문제를 고쳤습니다. |
| 명령 | `input.ts`의 모든 `ProjectShortcut`을 App 디스패처 하나(`run`)에 연결했습니다. 키보드·메뉴·툴바가 같은 경로를 씁니다. 피아노롤 범위의 음표 명령은 클립 편집으로 바꾸지 않습니다. |
| 이력 | 오디오 게인·페이드 슬라이더와 클립 이름 입력에 병합 키를 적용했습니다. 이름을 비우면 확정하지 않고, 포커스를 잃을 때 이전 이름으로 돌아갑니다(프로젝트·트랙·클립). |
| 포커스 | 마우스로 누른 툴바·트랜스포트 버튼과 스냅·루프 선택 상자는 포커스를 놓습니다. 다음 Space는 재생/정지입니다. |
| 도움말 | `SHORTCUT_TABLE`로 범위별 목록을 만들고, 플랫폼에 따라 ⌘ 또는 Ctrl 표기를 보여줍니다. |
| 피아노롤 재생선 | `PianoRollBridge`만 transport를 구독해 `playheadBeat`를 넘깁니다. App 전체는 25fps로 다시 그리지 않습니다. |

합성 이벤트를 사용했으므로 실제 하드웨어 포인터·IME·트랙패드 휠 자동화 검증은 아닙니다.

남은 일:
- 클립 루프(`loopClip`, L): 엔진 지원 전이며 현재는 ‘곧 지원’ 알림만 표시합니다. 데이터 모델에 `loop` 필드를 추가하지 않았습니다.
- 메트로놈(K): WebAudioEngine에 메트로놈이 없어 알림만 표시합니다.
- 퀀타이즈와 음표 삭제는 피아노롤이 처리합니다. 앱 수준에서는 동작하지 않습니다.
- MIDI 왼쪽 비파괴 트림(오프셋 필드)과 Alt+Shift MIDI alias 예약은 구현하지 않았습니다.
- 피아노롤 스냅은 타임라인 스냅과 별도로 둡니다(피아노롤에 셋잇단 값이 있음).

## 이번에 실제로 수정한 코드

| 영역 | 실제 변경 |
|---|---|
| 키보드 삭제 범위 | 타임라인 Delete는 선택 리전만 삭제합니다. 빈 선택이면 트랙으로 대체하지 않습니다. 피아노롤은 선택 음표가 없어도 Delete를 소비합니다. |
| 트랙 삭제 | 키보드 삭제의 자동 fallback을 제거했습니다. 현재 툴바 버튼은 실제 대상을 클립 삭제 또는 트랙 삭제라고 명시합니다. |
| 입력 보호 | 이미 처리된 이벤트, 한글 등 IME 조합, legacy 229, Process/Dead, AltGraph를 검사합니다. 네이티브 텍스트·선택·슬라이더·버튼 입력을 보호합니다. |
| AltGraph | Windows/Linux AltGr 문자 입력을 차단하고 macOS Option을 AltGraph로 보고하는 경우는 별도로 처리합니다. 플랫폼 차이 회귀 테스트를 추가했습니다. |
| 반복 입력 | 재생·삭제·Undo/Redo·저장은 첫 키 입력만 실행하며 앱이 소유하는 반복 이벤트의 브라우저 기본 동작도 막습니다. |
| 잘못된 키 제거 | Mod+D의 클립 복제와 plain S의 분할을 제거했습니다. Mod+T는 등록하지 않았습니다. 기존 복제·분할 툴바는 유지합니다. |
| 드래그 | 시작 임계값 4 CSS px, 상대 이동 스냅, 수평 이동 없는 음높이 변경에서 원래 시작점 보존을 적용했습니다. |
| 취소 | Escape, pointercancel, capture 상실, 창 blur, 문서 숨김, 컴포넌트 해제 시 제스처를 정리합니다. 취소와 최종 값이 같은 이동은 문서 변경을 확정하지 않습니다. |
| 모달 | 초기 포커스, Tab/Shift+Tab 순환, 닫은 뒤 포커스 복귀를 추가했습니다. |
| 이력 경계 | 키보드·툴바 Undo/Redo, 선택 전환, 프로젝트 교체에서 기존 변경 병합 상태를 끊습니다. |

## 자동 검증

- TypeScript 프로젝트 검사 통과.
- Vitest 4개 파일, **30개 테스트 통과**. 기존 22개에 입력·상대 스냅·플랫폼 구분 회귀 테스트 8개를 추가했습니다.
- 프로덕션 빌드 통과: Vite 8.3.5. 빌드 성공을 오디오 성능·장치 호환성 검증으로 간주하지 않습니다.

새 테스트는 명령 해석과 이동 계산 로직을 확인합니다. 실제 운영체제의 한글 IME 이벤트 순서나 물리 키의 길게 누르기를 자동화한 전체 브라우저 테스트는 아닙니다.

## 브라우저에서 직접 확인한 범위

클라우드 Chrome의 기존 데모 프로젝트에서 아래를 확인했습니다.

| 시나리오 | 관찰한 결과 |
|---|---|
| 음표 하나 삭제 후 Delete 추가 입력 | 음표 9개→8개, 리전 24개·트랙 6개 유지. 초점은 피아노롤에 남음. |
| 음표 삭제 Undo | 음표 9개로 복원. |
| 리전 하나 삭제 후 Delete 추가 입력 | 리전 24개→23개, 트랙 6개 유지. |
| 리전 삭제 Undo | 리전 24개로 복원, 원래 리전의 음표 9개 유지. |
| 도움말 열기 | 모달 내부 닫기 버튼으로 초기 초점 이동. 이전의 Mod+D·S 편집 키 안내가 제거됨. |
| 도움말 Tab/Shift+Tab·Escape | 키보드 초점이 모달 안에 유지되며, Escape로 닫은 뒤 도움말 버튼으로 복귀. 단일 버튼 도움말 모달에서 확인. |

검증에 사용한 삭제는 Undo로 복원했습니다. 저장된 원본 오디오를 영구 삭제하는 검증은 수행하지 않았습니다.
