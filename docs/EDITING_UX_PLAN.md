# 편집 사용성 명세 — 피아노롤·리전 (0.3.5)

작성: 2026-11-22 · 범위: 피아노롤 마우스/키보드 상호작용, 재생 위치 조작, 미리듣기, 드럼 입력, 리전 붙여넣기·반복.
배경: 직접 사용하며 보고된 불편(1절)을 고치고, 손에 익은 편집 흐름이 끊기지 않도록 정한 규칙입니다. 키 목록 전체는 [SHORTCUTS.md](SHORTCUTS.md)에 있습니다.

## 1. 보고된 불편과 원인

| 보고 | 원인 (코드) |
|---|---|
| 음 선택 후 Shift+↑↓로 옥타브 이동이 안 됨 | Shift+방향키가 "선택 확장"에 묶여 있었고 옥타브는 Alt+Shift+↑↓ (`PianoRoll.tsx` handleKeyDown) |
| 그냥 클릭해도 음이 생김. 그리기 모드가 없음 | 빈칸 단일 클릭 = 음 추가 (`endMarquee` → `addNoteAt`) |
| 피아노롤에서 재생 바를 잡아 옮길 수 없음 | 룰러·플레이헤드에 포인터 처리 없음 (`pointer-events: none`) |
| 맨 처음으로 가는 단축키가 없음 | `Home`은 프로젝트 0으로 이동 → 클립이 뒤에 있으면 피아노롤 플레이헤드가 사라져 반응이 없는 것처럼 보임. 건반 버튼에 포커스가 있으면 `Home`·방향키가 컨트롤 키로 빠짐 |
| 방향키 상호작용이 들쭉날쭉 | 선택이 없을 때 방향키는 아무 일도 안 함 |
| 선택 없을 때 Shift+방향키 = 줌이었으면 | 없음 |
| 왼쪽 건반을 누르면 소리가 나야 하고, 선택한 음이 건반에 색으로 보여야 함 | 건반은 `click`(손을 뗄 때)에만 미리듣기, 선택 음높이 표시 없음 |
| 드래그 선택이 잘 안 되고, 선택한 음이 소리 나지 않음 | 빈칸 클릭이 음 추가와 겹침. 마키 선택에는 미리듣기 없음 |
| 드럼 음이 너무 짧게 생김 | 드럼 기본 길이 0.25박 고정 (`lastRef.drum`) |
| 리전 연속 붙여넣기가 안 됨, 반복 배치가 맞추기 어려움 | 붙여넣기는 항상 재생 위치에 → 두 번째 붙여넣기가 같은 자리에 겹침. 반복(`⌘R`) 간격이 리전 실제 길이라 격자에서 어긋남 |

## 2. 원칙

- **실수로 음이 생기지 않게.** 기본은 선택 모드, 음을 만들 때만 그리기 모드(또는 더블 클릭).
- **같은 키는 어디서나 같은 뜻.** 방향키 = 이동, Shift = 크기(길이·옥타브), 선택이 없으면 보기(재생 위치·스크롤·줌).
- **보이는 피드백.** 선택 음높이는 건반에, 편집하는 음은 소리로, 키보드로 고른 음은 화면 안으로.
- **반복은 격자 위에.** 붙여넣기·반복 간격은 박(또는 더 큰 스냅)으로 올려 끝과 끝이 맞게.

## 3. 적용 명세

### 3.1 피아노롤 마우스

- 상단 도구 버튼 **선택 ⇄ 그리기**, 단축키 `B`. `⌘`/`Ctrl`을 누른 채 빈칸을 누르면 그 한 번만 그리기.
- 선택 모드: 빈칸 클릭 = 선택 해제 + (정지 중) 재생 위치 이동 · 빈칸 드래그 = 마키 · 빈칸 더블 클릭 = 음 추가 · 음 더블 클릭 = 삭제.
- 그리기 모드: 빈칸 누르기 = 음 추가, 그대로 오른쪽으로 끌면 길이가 격자 단위로 늘어남 · 음 클릭 = 삭제.
- 새 음과 그리기는 표시 격자(스냅을 고르면 그 단위)에 맞춤. `⌃⇧`/`Ctrl+Shift`는 격자 무시.
- 마키 선택 중 새로 선택된 음높이를 미리듣기(한 번에 최대 4개).

### 3.2 피아노롤 키보드

| 키 | 선택 있음 | 선택 없음 |
|---|---|---|
| ←→ | 격자 한 칸 이동 | 재생 위치 격자 한 칸 |
| ↑↓ | 반음 (드럼: 한 행) | 세로 스크롤 |
| Shift+↑↓ | 옥타브 (드럼: 한 행) | 세로 줌 (↑ 확대) |
| Shift+←→ | 길이 ± 격자 | 가로 줌 (→ 확대) |
| Alt+←→ / Alt+↑↓ | 이전/다음 음, 위/아래 음 선택 | 첫/마지막 음 선택 |
| Alt+Shift+방향키 | 선택 확장 | — |
| Home / End | 클립 시작 (한 번 더: 프로젝트 처음) / 클립 끝 | 같음 |
| B | 그리기 모드 켬/끔 | 같음 |

건반 버튼은 Tab 포커스를 받지 않아(`tabIndex=-1`), 건반을 누른 뒤에도 방향키·Home이 편집기로 갑니다. 키보드로 음높이를 바꾸거나 음을 고르면 그 음이 보이도록 스크롤합니다.

### 3.3 재생 위치

- 룰러 클릭 = 그 위치로 이동(표시 격자, Shift는 자유). 드래그로 스크럽. 재생 중에는 화면 플레이헤드만 따라가고 손을 뗄 때 한 번 이동(0.3.4 타임라인과 같은 규칙).
- 빈칸 오른쪽 클릭 메뉴: **여기로 재생 위치 이동**.

### 3.4 건반 열

- `pointerdown`에서 미리듣기, 누른 채 위아래로 끌면 지나가는 음마다 미리듣기. 그 음높이의 음표를 선택(Shift: 추가).
- 선택된 음의 음높이는 건반이 트랙 색으로 칠해짐.

### 3.5 보기·소리

- `♪ 소리`: 편집 중 미리듣기(클릭·마키·방향키) 켜고 끄기, 브라우저별로 기억. 건반은 항상 소리.
- `접기`: 음표가 있는 음높이만 보기.

### 3.6 드럼

- 새 드럼 음 기본 길이 = max(스냅 격자, 반 박). 그리기 모드에서 끌면 원하는 길이. 길이를 바꾸면 그 길이를 다음 음에 씀.

### 3.7 리전·음표 붙여넣기와 반복

- `⌘V`: 재생 위치에 붙여넣고, 정지 중이면 재생 위치를 붙여넣은 블록 끝(박/스냅 올림)으로 옮겨 연속 붙여넣기가 이어짐. 타임라인과 피아노롤 공통.
- `⌘R` 반복, 피아노롤 `⌘D` 복제: 간격 = 선택 범위를 박(또는 더 큰 스냅)으로 올림 → 3.9박짜리 리전도 4박 간격으로 반복.
- 리전 메뉴 **여러 번 반복 ×2 / ×3 / ×4 / ×8 / ×16**.

## 4. 다음 후보

- 재생 따라 자동 스크롤, 스케일 하이라이트, 음 자르기/합치기, 벨로시티 램프 그리기, 시간 범위 선택 복제.
- 타임라인 `⌘D`를 리전 복제로 바꿀지: 현재 `⌘D`는 트랙 복제라 결정이 필요합니다.
