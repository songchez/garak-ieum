# 가락이음 브랜드

2026-10-30 사용자 확정 사항입니다.

- 제품명: **가락이음**
- 영문 식별 표기: Garak Ieum / `garak-ieum`
- 로고: 삼태극 북과 세 줄의 멀티트랙. 북채 없는 1:1 이미지.
- 로고 파일: `public/brand/garak-ieum-mark.png`
- 이름 글꼴: 국립한글박물관 **덕온공주체**, 가로쓰기용 원본.
- 이름 표시 파일: `public/brand/garak-ieum-wordmark.svg`. 고정된 네 글자만 원래 획과 배치 폭으로 조판한 SVG입니다. 약 7.9MB의 원본 폰트를 웹에서 내려받거나 설치하지 않습니다.
- 이미지와 이름은 별도 요소로 배치합니다. 이름을 로고 이미지 안에 합성하지 않습니다.
- 글자색: 따뜻한 미색 `#f0e2be`. 기존 다크 테마에서 사용합니다.
- 앱 상단과 소개 창에서 동일한 `Brand` 컴포넌트를 사용합니다.
- 프로젝트 파일 확장자: `.garak`. 이전 `.noct` 파일도 계속 열 수 있습니다.
- 새 명칭을 적용해도 기존 IndexedDB 이름(`noct-studio`)과 파일 내부 포맷 식별자(`format: "noct-studio"`)는 호환성을 위해 유지합니다.

## 색과 장식

방향: **먹과 한지 위의 단청**. 작업 화면은 어둡고 차분하게 두고, 전통 색과 문양은 경계와 강조에만 사용합니다. 모든 색은 `src/styles.css` 맨 위의 `:root` 변수로 관리합니다.

| 변수 | 용도 |
|---|---|
| `--ink-09` ~ `--ink-99` | 먹색 중성 단계. 숫자는 명도(%)입니다. 어두운 면(09–30)은 1% 단위, 글자·밝은 면은 3% 단위입니다. |
| `--seokganju-36` ~ `--seokganju-69` | 석간주 주 강조색 단계. 재생·내보내기·주요 버튼, 선택 상태 |
| `--hanji` | 한지색 `#f0e2be`. 워드마크 글자색 |
| `--dancheong-red / -green / -blue / -gold` | 단청 장식선과 보조 강조 |
| `--giwa`, `--giwa-edge` | 기와 장식 |

- 헤더 아래 경계: 담장 기와의 용마루·기왓골·수막새를 표현한 기존 인라인 SVG를 사용합니다. 작업 화면에서는 원본 16:14 비율을 유지해 높이 8px의 얇은 경계로 표시합니다.
- 트랙 색(오방색·단청 계열): 주홍 `#e38457`(드럼), 석록 `#7fb59a`(베이스), 삼청 `#6f9fd0`(건반), 옥색 `#8cc7c0`(패드), 연지 `#d98a9f`(플럭), 석황 `#d9b45a`(하이햇), 황토 `#c9a06a`(오디오).
- 이전에 저장된 프로젝트의 트랙 색은 파일에 저장된 값을 그대로 유지합니다.

글꼴의 출처와 이용 조건은 [제3자 자산 안내](../THIRD_PARTY_NOTICES.md)에 명시합니다. 이 글꼴에는 애플리케이션 코드의 MIT 라이선스가 적용되지 않습니다.

## 작업 화면의 상단 밀도

2026-11-01 사용자 요청: 한옥 분위기를 유지하면서 상단 로고·여백과 재생/정지 바의 높이를 줄여 리전 편집 공간을 확보합니다.

| 요소 | 변경 전 기본값 | 컴팩트 배치 |
|---|---|---|
| 로고·프로젝트 헤더 | 58px | 40px, 기와 경계 포함 |
| 재생·정지·녹음 바 | 64px | 42px |
| 두 영역 합계 | 122px | 82px |
| 기와 경계 | 14px | 8px, 원본 비율 유지 |
| 상단 로고 | 28×28px | 20×20px |
| 상단 워드마크 | 높이 26px | 높이 18px, 원본 SVG 비율 유지 |

위 수치는 CSS 설정값입니다. 기존 높이 760px 이하 화면은 합계 109px였으므로 27px를, 폭 780px 이하·높이 760px 초과 화면은 108px였으므로 26px를 확보하는 계산입니다. 기본 화면은 40px 감소합니다. 새로운 상단 높이는 좁거나 낮은 화면에서 다시 커지지 않습니다.

- 삼태극 북 로고, 덕온공주체 워드마크, 먹·한지·석간주 색상과 기와 SVG 원본을 사용합니다. 소개 창의 큰 로고는 기존 크기를 유지합니다.
- 상단 주요 버튼의 클릭 영역은 높이 28px, BPM 입력은 높이 24px입니다. 시간은 마디/박과 분/초 두 줄을 유지하며 줄 사이 여백을 줄입니다.
- 긴 프로젝트 이름은 입력 폭 안에서 편집합니다. 저장 상태와 파일 작업 버튼은 축소하지 않으며 저장 실패·불러오는 중 문구를 숨기지 않습니다.
- 폭 780px 이하에서도 Undo/Redo를 재생 바에 유지합니다. 루프 길이·박자표 등 보조 항목은 기존 폭별 표시 정책을 따릅니다.
- 상단 포커스 외곽선은 작은 높이 안에서 잘리지 않도록 조정합니다. 작업 중 알림 위치는 두 바의 높이를 기준으로 계산합니다.

관련 레이아웃은 [`StudioHeader.css`](../src/components/StudioHeader.css)에서 관리하고, 다른 편집기·트랙의 공통 `.icon-button` 크기는 유지합니다.

실제 화면 확인 대상은 1440×900, 1024×768, 780/781×800, 620×720, 1440×600입니다. 긴 한글 이름, 저장 실패·불러오는 중, Tab 포커스, 재생·정지·녹음 상태, 내보내기 상태를 함께 확인합니다. 이번 환경에서는 검증 브라우저가 개발 서버에 연결되지 않아 해당 화면 측정과 스크린샷 검증은 남아 있습니다.

## 워드마크 재생성

공식 TTF ZIP에서 `DeogonPrincess.ttf`를 꺼낸 뒤 fonttools 4.61.1이 있는 Python 환경에서 실행합니다.

```sh
python3 scripts/build-brand-wordmark.py --font /path/to/DeogonPrincess.ttf
```

이 과정은 글꼴 파일을 수정하는 서브셋 생성이 아니라 제품명의 고정된 네 글자를 그래픽으로 조판합니다. 글꼴 전체와 변환된 글꼴 파일은 GitHub·웹 빌드에 포함하지 않습니다.
