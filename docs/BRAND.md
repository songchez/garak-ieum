## 선택 가능한 한국 전통색 테마

2026-11-02: **설정 → 화면 테마**에서 기존 새벽 한옥과 신규 5종을 선택합니다. 최초 기본값은 새벽 한옥이며, 선택한 ID를 브라우저에 저장합니다. 화면 테마와 오디오 설정의 초안·적용은 별개입니다.

| 테마 | 작업면·구획 | 글자·선택·강조 |
|---|---|---|
| 단청 | 뇌록 계열의 어두운 면, 삼청 입력 영역, 석간주 기와 | 밝은 한지 계열 글자, 황단 선택·루프, 장단 녹음 |
| 백자와 수묵 | 유백 작업면·패널, 한지 바탕 | 농묵 본문, 청화 선택·포커스, 담묵 경계·비활성 |
| 고려비색과 상감 | 담록 바탕·선택 면, 백상감 패널 | 흑상감 글자, 비색 경계·기와, 읽을 수 있게 짙게 조정한 비색 조작부 |
| 천연염색 한복 | 따뜻한 비단빛 작업면, 옥색 계열 선택 면 | 쪽빛 선택, 소목 브랜드, 치자 루프, 홍화 계열 녹음 |
| 돌담과 기와 | 기와색 패널, 솔잎색 선택 면 | 밝은 중성 글자, 황토 계열 조절기, 화강석 경계 |
| 새벽 한옥 | 기존 먹회색 작업면과 패널 | 기존 한지·청자·석간주·황동 역할 |

원색 목록과 실제 역할 토큰은 [`core/theme.ts`](../src/core/theme.ts)에 함께 보관합니다. 밝은 테마에서는 파스텔 원색을 작은 글자로 직접 사용하지 않고 면과 경계에 배치합니다. 글자·포커스·상태색은 대비가 확보되는 파생 명도를 사용합니다. 원색의 루프 면(`--loop-fill`)과 읽는 금색 글자(`--brass`)도 구분합니다. 전체 역할·계산값·검증 범위는 [THEMES](THEMES.md)에 있습니다.

워드마크는 기존 SVG의 획을 마스크로 사용합니다. 밝은 배경에서는 테마 본문색으로 표시하며, 원본 글자 형태와 로고 파일은 바꾸지 않습니다. 기와는 기존 SVG 형태와 8px 높이를 유지하고 신규 테마의 재료색을 입힙니다. 프로젝트의 트랙·리전 색상값은 바꾸지 않으며 라벨 전경만 실제 배경에 맞춰 선택합니다.

[6종 색 배치 PNG](assets/korean-theme-presets.png) · [원본 SVG](assets/korean-theme-presets.svg)는 테마 레지스트리의 색으로 만든 설계 자료입니다. 실제 앱 스크린샷이나 브라우저 시각 검증 결과가 아닙니다.

## 새벽 한옥의 기본 색과 장식

2026-11-02 방향: **새벽 한옥**. 먹과 한지의 차분한 인상을 유지하면서, 새벽빛이 드는 한옥처럼 패널을 조금 더 밝고 맑은 회색으로 올립니다. 청자·옥색은 일반 선택과 포커스, 석간주는 브랜드 포인트, 옅은 황동색은 루프와 마커에 사용합니다. 전통적인 인상은 색의 조합과 기존 기와 경계에서 만들고 작업 영역에 문양이나 질감을 추가하지 않습니다.

새벽 한옥의 기존 호환 음영은 `src/styles.css` 맨 위의 `:root`에서 유지합니다. 선택 가능한 테마의 원색·역할 매핑은 `src/core/theme.ts`에서 관리하며, 화면에는 역할이 명확한 변수를 우선 사용합니다. 아래 표는 새벽 한옥 기본값의 이전·현재 비교입니다.

| 역할 | 이전 | 현재 | 변수 |
|---|---|---|---|
| 앱 바탕 | `#191815` | `#232927` | `--surface-base` |
| 편집 캔버스 | `#1c1a17` | `#252c28` | `--surface-canvas` |
| 패널 | `#221f1c` | `#303831` | `--surface-panel` |
| 도구 막대·높은 면 | `#272520` | `#394139` | `--surface-raised` |
| 본문 | `#e3dfd9` | `#eee9dc` | `--text-primary` |
| 작은 보조 글자 | `#877e6e` / `#96876e` | `#b8beaf` | `--text-muted` |
| 일반 활성 | 석간주 `#d28670` | 청자 `#9bc8b5` | `--accent` |
| 키보드 포커스 | `#d5907b` | `#b4dac9` | `--focus` |
| 내보내기·브랜드 포인트 | `#d28670` | `#e0a08a` | `--brand-accent` |
| 루프·마커 | `#d4a84b` | `#d4ba7e` | `--brass` |

- `--surface-*`는 캔버스·패널·입력·팝업·선택 영역을 구분합니다. 편집 캔버스는 패널보다 어둡게, 도구 막대와 팝업은 한 단계 밝게 유지합니다.
- `--text-primary / -secondary / -muted / -disabled / -inverse`는 글자의 역할을 구분합니다. 밝아진 면에 맞춰 작은 시간 표시, BPM 라벨, 악기 설명, 노브 이름, 메뉴 단축키도 함께 밝힙니다. 비활성·꺼진 상태의 구분은 유지합니다.
- `--border-subtle / -default / -strong`은 영역 경계와 조작부 경계를, `--grid-major / -minor`는 편집 격자의 두 단계를 관리합니다.
- `--accent`, `--accent-soft`, `--accent-border`, `--focus`는 탭·선택·드래그·검색 입력·메뉴 등 일반 조작 상태에 공통으로 사용합니다. 재생은 녹색, 녹음은 빨강, 루프는 황동색으로 구별합니다. 뮤트·솔로·모니터의 기존 기능별 색상은 유지합니다.
- 기존 `--ink-09` ~ `--ink-99` 이름은 세부 음영을 위한 호환 단계로 유지합니다. 숫자를 실제 명도 백분율로 해석하지 않습니다. `--seokganju-*`는 브랜드 포인트에, `--hanji` `#f0e2be`는 원래 워드마크와 재생 커서에 사용합니다.
- 헤더 아래 경계는 담장 기와의 용마루·기왓골·수막새를 표현한 기존 인라인 SVG 그대로 사용합니다. 원본 16:14 비율을 유지해 높이 8px의 얇은 경계로 표시합니다.
- 트랙 색(오방색·단청 계열)은 주홍 `#e38457`(드럼), 석록 `#7fb59a`(베이스), 삼청 `#6f9fd0`(건반), 옥색 `#8cc7c0`(패드), 연지 `#d98a9f`(플럭), 석황 `#d9b45a`(하이햇), 황토 `#c9a06a`(오디오)입니다. 저장된 프로젝트의 트랙·클립 색 값과 사용자 지정 아이콘 식별자는 그대로 유지합니다.

앱 기능 아이콘에는 Lucide의 선형 SVG를 사용합니다. 메뉴의 체크 표시와 기능 아이콘은 별도 열로 배치해 선택 상태와 아이콘 미리 보기를 함께 읽을 수 있게 합니다. 삼태극 북 로고와 덕온공주체 워드마크는 별도의 기존 브랜드 자산입니다.

[팔레트·아이콘 비교 PNG](assets/hanji-theme-preview.png) · [원본 SVG](assets/hanji-theme-preview.svg). 이전 기준 커밋과 현재 CSS 토큰 및 실제 Lucide SVG를 사용한 디자인 자료이며, 실제 앱 화면을 캡처한 자료는 아닙니다.

## 작업 화면의 상단 밀도

2026-11-02: 로고·프로젝트 이름과 재생·정지·녹음 컨트롤을 **하나의 상단 바**로 합칩니다. 왼쪽에는 브랜드와 프로젝트 정보, 가운데에는 재생·시간·BPM, 오른쪽에는 파일 작업을 배치합니다. 기와는 합쳐진 바의 아래 경계입니다.

| 요소 | 변경 전 기본값 | 통합 배치 |
|---|---|---|
| 상단 구조 | 로고·프로젝트 헤더 + 독립 재생 바, 두 줄 | 세 그룹을 한 줄에 배치 |
| 전체 높이 | 58px + 64px = 122px | 48px: 내용 40px + 기와 8px |
| 기와 경계 | 14px | 8px, 원본 비율 유지 |
| 상단 로고 | 28×28px | 20×20px |
| 상단 워드마크 | 높이 26px | 높이 18px, 원본 SVG 비율 유지 |

위 수치는 CSS 설정값입니다. 처음 두 줄을 각각 줄였던 82px 배치에서 한 줄 48px로 다시 수정해 34px를 더 확보합니다. 원래 기본 화면 대비 74px, 기존 높이 760px 이하의 109px 배치 대비 61px 감소합니다. 좁거나 낮은 창에서도 상단 높이를 늘리거나 두 번째 바로 감싸지 않습니다.

- 삼태극 북 로고, 덕온공주체 워드마크, 먹·한지·청자·석간주 색상과 기와 SVG 원본을 사용합니다. 소개 창의 큰 로고는 기존 크기를 유지합니다.
- 프로젝트 이름(22px)과 저장 상태(12px)는 같은 왼쪽 그룹 안에 배치합니다. 저장 실패·불러오는 중 텍스트를 좁은 폭에서도 유지하고 이름 입력만 남는 폭에서 줄입니다.
- Undo/Redo, 처음으로, 정지, 재생/일시 정지, 녹음, 사이클 버튼은 모든 지원 폭에서 남깁니다. 주요 버튼의 클릭 영역은 높이 28px, BPM 입력은 높이 24px입니다. 마디/박과 분/초 표시도 유지합니다.
- 새 프로젝트·열기·저장·내보내기는 항상 접근할 수 있습니다. 텍스트를 숨기는 폭에서는 28px 아이콘 버튼으로 표시하고 접근성 이름과 툴팁을 제공합니다.
- 상단 포커스 외곽선은 작은 높이 안에서 잘리지 않도록 조정합니다. 작업 중 알림은 단일 헤더 아래 8px에 표시합니다.

| 창 너비 | 표시 정책 |
|---|---|
| 1250px 초과 | 워드마크, 박자표, 루프 길이, 파일 버튼 텍스트까지 표시 |
| 901–1250px | 파일 버튼은 아이콘으로 표시하고 박자표·루프 길이 보조 항목을 숨김 |
| 681–900px | 워드마크 대신 작은 로고 유지, 시간 표시와 가로 간격 축소 |
| 620–680px | 가로 간격을 추가로 축소하며 프로젝트 이름·저장 상태와 핵심 버튼 유지 |

관련 레이아웃은 [`StudioHeader.css`](../src/components/StudioHeader.css)에서 관리합니다. `App.tsx`의 `Transport`는 헤더 안에 한 번만 렌더링하며 독립 바 높이·배경·하단선·빈 공간 요소가 없습니다. 재생 시계 구독은 기존 `Transport` 컴포넌트 안에 유지하고, 다른 편집기·트랙의 공통 `.icon-button` 크기는 유지합니다.

실제 화면 확인 대상은 1440×900, 1024×768, 780/781×800, 620×720, 1440×600과 새 반응형 경계(1250/1251, 900/901, 680/681px)입니다. 긴 한글 이름, 저장 실패·불러오는 중, Tab 포커스, 재생·정지·녹음 상태, 내보내기 상태를 함께 확인합니다. 검증 브라우저의 개발 서버 연결이 차단되어 실제 화면 측정과 스크린샷·클릭 검증은 남아 있습니다. 소스 기반 너비 검토와 빌드 결과를 화면 검증으로 간주하지 않습니다.

## 워드마크 재생성

공식 TTF ZIP에서 `DeogonPrincess.ttf`를 꺼낸 뒤 fonttools 4.61.1이 있는 Python 환경에서 실행합니다.

```sh
python3 scripts/build-brand-wordmark.py --font /path/to/DeogonPrincess.ttf
```

이 과정은 글꼴 파일을 수정하는 서브셋 생성이 아니라 제품명의 고정된 네 글자를 그래픽으로 조판합니다. 글꼴 전체와 변환된 글꼴 파일은 GitHub·웹 빌드에 포함하지 않습니다.
