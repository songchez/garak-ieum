# 국악 샘플 프로젝트

프로젝트 선택 화면에서 시작할 수 있는 오리지널 MIDI 편곡 세 곡이다. 각 템플릿은 가야금·대금·해금·사물 타악의 실제 내장 샘플을 사용하고, 트랙별 음표·리전·악기 설정·이펙트·믹서 값을 모두 편집할 수 있다. 템플릿을 열 때마다 새 프로젝트와 새 편집 객체 ID를 만든다.

## 구성

| 템플릿 | ID | 장르 | BPM | 조성 | 마디 | 트랙 | 리전 | 음표 | 편곡 길이 |
|---|---|---|---:|---|---:|---:|---:|---:|---:|
| 마당의 결 | `madang-boombap` | 국악 붐뱁 | 92 | D minor pentatonic | 40 | 10 | 138 | 989 | 약 1:44 |
| 검은 물결 | `heukryu-trap` | 국악 트랩 | 144 | F♯ minor | 48 | 11 | 184 | 1,368 | 1:20 |
| 달빛 행렬 | `dalbit-fusion` | 퓨전 국악 | 118 | A Dorian | 40 | 11 | 177 | 1,488 | 약 1:21 |

위 BPM·조성·노트·길이는 이 프로젝트를 위해 정한 값이다. 참고곡을 채보하거나 원곡의 BPM·조성을 측정한 결과가 아니다. 길이는 4/4 타임라인 기준이며 리버브의 잔향은 별도다.

모든 곡은 처음부터 국악 악기가 연주된다. 전곡을 들을 수 있도록 사이클은 기본으로 꺼져 있고, 첫 번째 훅의 8마디를 사이클 범위로 미리 잡았다. 각 편곡은 2마디 단위의 명시적인 리전으로 구성되며, 무한 반복 리전 없이 곡 끝까지 다른 섹션으로 이어진다.

## 1. 마당의 결 — 국악 붐뱁

### 편곡 지도

화면에 보이는 마디 번호는 1부터 센다.

| 마디 | 마커 | 변화 |
|---|---|---|
| 1–4 | 문 열기 · 가야금 | 가야금·북·징으로 시작. 뒤의 2마디에 드럼·베이스·대금 진입 |
| 5–12 | 첫 마당 · Verse A | 낮은 베이스, 느슨한 하이햇, 여백이 많은 가야금 문장 |
| 13–20 | 함께 · Hook | 높은 가야금 선율과 대금·해금 응답, 킥·장구 보강 |
| 21–24 | 숨 · 장구 응답 | 킥·스네어를 비우고 장구·가야금·대금이 전면으로 이동 |
| 25–32 | 둘째 마당 · Verse B | 다른 순서의 모티프, 낮은 가야금 응답과 해금 진입 |
| 33–36 | 다시 함께 · Hook | 훅을 압축해 재등장 |
| 37–40 | 마당을 나서며 | 리듬을 줄이고 마지막 2마디에는 북과 가야금의 여운 |

10개 트랙: 로파이 킥·스네어, 하이햇, 북·좌고, 장구, 징·꽹과리, 베이스, 가야금 주선율, 낮은 가야금 응답, 대금, 해금.

하이햇의 엇박을 0.055박 늦추고 강약을 바꾸어 정박 킥과 느슨하게 맞물리게 했다. 스네어는 기본적으로 2·4박을 유지하며 문장 끝에서 고스트 노트와 필이 나온다. 가야금 주선율의 짧은 음표, 대금의 긴 숨, 해금의 부드러운 응답을 교대로 배치했다. 저역은 D·C·G를 중심으로 D–F–G–A–C의 다섯 음 안에서 움직인다.

## 2. 검은 물결 — 국악 트랩

### 편곡 지도

| 마디 | 마커 | 변화 |
|---|---|---|
| 1–4 | 수면 · Intro | 첫 박의 가야금·북·징, 뒤이어 얇은 하이햇과 해금 |
| 5–12 | 첫 물결 · Verse A | 하프타임 클랩, 짧은 808 킥, 긴 서브 베이스 |
| 13–20 | 너울 · Hook | 16분 하이햇, 32분/셋잇단 롤, 높은 가야금과 대금 |
| 21–24 | 물밑 · Break | 킥·클랩을 비우고 장구·대금·가야금의 응답 |
| 25–32 | 깊은 물결 · Verse B | 베이스 루트 순서와 가야금 끝말 변화 |
| 33–44 | 큰 너울 · Final hook | 12마디 동안 세 번 변하는 악기 조합과 선율 |
| 45–48 | 잔물결 · Outro | 비트를 줄이고 가야금의 F♯ 종지 |

11개 트랙: 808 킥, 스네어·클랩, 하이햇, 북, 장구, 징·꽹과리, 서브 베이스, 가야금, 대금, 해금, 패드.

킥은 `kit-808`의 짧은 킥(MIDI 35)을 써서 별도 서브 베이스와 겹치는 긴 저역을 줄였다. 144 BPM에서 스네어의 강박을 각 마디의 3박에 두었고, 훅 하이햇은 더 촘촘해진다. 패드는 훅과 브레이크에만 낮게 깔리고, 대금·해금은 교대로 답한다. 서브 베이스는 현재 합성 베이스의 노트·엔벌로프를 이용한다. 엔진에 없는 포르타멘토나 808 글라이드를 전제로 하지 않는다.

## 3. 달빛 행렬 — 퓨전 국악

### 편곡 지도

| 마디 | 마커 | 변화 |
|---|---|---|
| 1–4 | 행렬이 오다 · Intro | 가야금·장구·북과 낮은 베이스, 뒤이어 밴드와 대금 |
| 5–12 | 메기다 · Theme A | 대금이 앞 마디, 해금이 뒤 마디에서 답하는 두 마디 문장 |
| 13–20 | 함께 걷다 · Chorus | 라이드, 짧은 전기 피아노 화음, 높은 가야금 장식 |
| 21–24 | 돌아보다 · Break | 어쿠스틱 킥·스네어를 비우고 두 베이스 역할을 번갈아 노출 |
| 25–32 | 받다 · Theme B | 선율·베이스 순서를 바꾸고 화음을 선택적으로 진입 |
| 33–36 | 달빛 행렬 · Return | 훅 재등장, 대금·해금의 새로운 끝말 |
| 37–40 | 멀어지는 발소리 | 밴드가 물러나고 마지막 북·가야금으로 마무리 |

11개 트랙: 어쿠스틱 킥·스네어, 하이햇·라이드, 낮은 베이스, 높은 응답 베이스, 북·박, 장구, 꽹과리·징, 가야금, 대금, 해금, 전기 피아노.

베이스 1은 짧은 저음과 옥타브로 일정한 추진력을 만들고, 베이스 2는 더 높은 음역과 짧은 어택으로 그 사이에 응답한다. 대금은 각 2마디 리전의 앞 4박을, 해금은 뒤 4박을 사용한다. A Dorian의 F♯를 선율과 D 화음에 넣어 어두운 단조에만 머물지 않게 했다. 장구의 3+3+2 강조는 4/4 밴드 비트와 맞물리는 새 패턴이며, 특정 전통 장단의 원형을 그대로 재현했다고 표기하지 않는다. 판소리 보컬 녹음은 포함하지 않는다.

## 악기와 믹스

실제 악기 ID와 키트 매핑은 `src/core/instruments.ts`, 샘플 존은 `public/samples/<set>/manifest.json`을 따른다.

| 소리 | 사용한 ID / MIDI 번호 | 배치 의도 |
|---|---|---|
| 국악 선율 | `gayageum`, `daegeum`, `haegeum` | 가야금 45–78, 대금 66–79, 해금 62–78 범위 안에서 편곡. 숫자는 옥타브 이름 혼동을 피하기 위한 MIDI 번호 |
| 북·박·좌고 | `samul` 36·37·45 | 강박·발걸음·낮은 응답 |
| 장구 | `samul` 38·39·40·41·43 | 덩·기덕·덕·쿵·더를 구분한 강약과 필 |
| 꽹과리·징 | `samul` 42·44·49·51 | 장면 시작과 훅의 드문 강조 |
| 드럼 키트 | `kit-lofi`, `kit-808`, `kit-acoustic` | 붐뱁·트랩·밴드의 서로 다른 어택과 리듬 |
| 베이스·화음 | `bass`, `pad`, `rhodes` | 내장 합성 악기, 외부 플러그인 불필요 |

모든 샘플 음표는 해당 매니페스트의 실제 존 안에 있고, 808에 없는 MIDI 37 같은 패드는 사용하지 않는다. 대금 세트의 자체 +8 dB 보정을 고려해 트랙 볼륨을 낮게 잡고, 금속 타악은 섹션 변화에만 얹었다. 저역은 중앙에 가깝게, 가야금과 타악 응답은 좌우에 나누었다. 리버브·딜레이는 짧고 낮게 설정하여 선율의 시작점을 보존하고, 드럼 일부에만 완만한 컴프레서를 적용했다. 마스터 볼륨은 0.74다.

국악 샘플의 출처는 **국립국악원 국악기 디지털 음원**이며, 기존 샘플 라이선스와 출처 표기를 그대로 사용한다. 드럼 세트별 출처·라이선스도 기존 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 및 각 세트의 `LICENSE.txt`를 따른다. 상세 매핑과 샘플 규격은 [SAMPLES.md](SAMPLES.md)에 있다. 이번 변경으로 추가한 음원 파일은 없다.

## 구현과 검증

- 공개 카탈로그: `src/core/projectTemplates.ts`
- 개별 편곡: `src/core/projectTemplates/boombap.ts`, `trap.ts`, `fusion.ts`
- 공통 MIDI 생성: `src/core/projectTemplates/shared.ts`
- 테스트: `src/core/projectTemplates.test.ts`

`createTemplateProject(id)`는 알려진 템플릿만 만들며, 알 수 없는 ID에는 오류를 반환한다. `create()`는 오디오 로드·재생·저장 없이 Project만 만드는 순수 팩토리다. 호출마다 프로젝트·트랙·디바이스·마커·리전·노트 객체와 ID가 새로 생기고, 음악 내용은 같은 결과를 낸다. 따라서 선택 화면의 실제 편곡 미리보기와 사용자가 여는 새 프로젝트가 상태를 공유하지 않는다.

자동 검증은 다음을 확인한다.

- `validateProject()` 통과와 카탈로그 BPM·마디 수의 일치.
- 두 번 만든 프로젝트의 ID 격리와 편집 객체 독립성.
- 트랙의 리전 겹침 없음, 섹션 경계 준수, 모든 노트의 리전 내부 수용.
- 샘플 존 존재와 선택되는 모든 샘플의 WebM/AAC 파일 존재.
- 세 곡의 조성, 선율 악기 음역, 관악·찰현·베이스의 단선율 구성.
- 첫 박의 국악 진입, 섹션별 밀도 변화, 선율 변형, 얇아지는 마지막 부분.
- 붐뱁의 늦은 엇박, 트랩의 하프타임과 하이햇 롤, 퓨전의 두 베이스 및 앞뒤 마디 응답.

자동 검증 명령:

```sh
pnpm exec vitest run src/core/projectTemplates.test.ts
pnpm exec tsc -b --pretty false
```

새 편곡은 내장 단음 샘플과 MIDI 노트·벨로시티로 표현한다. 지속적인 농현·추성·퇴성·호흡 변화나 실제 판소리의 발성까지 모델링한 연주기는 아니다. 구조·매핑 검증과 별개로, 최종 음량·잔향·악기 균형은 실제 브라우저 오디오 출력에서 확인할 수 있다.
