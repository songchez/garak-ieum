# 메트로놈

헤더의 템포(BPM) 옆에 메트로놈이 있습니다. 클릭은 **모니터 출력에만** 나옵니다. 트랙, 녹음 테이크, WAV 내보내기·바운스에는 들어가지 않습니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 켜기/끄기 | 메트로놈 버튼 또는 `K` |
| 설정 열기 | 버튼 옆 ▾ |
| 소리 고르기 | 설정의 **기본 소리**나 **국악 타악기**에서 선택합니다. 고르면 한 마디를 미리 들려줍니다. |
| 음량 | 0–100 % 슬라이더. ▶로 한 마디를 미리 듣습니다. |
| 첫 박 강세 | 켜면 마디 첫 박을 강한 소리로 냅니다. 6/8·9/8·12/8 같은 겹박자는 점4분음표 묶음의 첫 박도 구분합니다. 끄면 모든 박이 같은 소리입니다. |
| 녹음할 때만 소리 내기 | 일반 재생에서는 조용하고, 녹음과 카운트인 동안에만 클릭합니다. |
| 녹음 카운트인 | 끔 · 1마디 · 2마디. `⇧K`(Shift+K)로 끄고 켭니다. 다시 켜면 마지막에 쓴 마디 수(처음엔 1마디)로 돌아갑니다. 정지 상태에서 녹음을 시작하면 그만큼 먼저 클릭한 뒤 재생과 녹음을 정확히 다음 박에 시작합니다. 메트로놈이 꺼져 있어도 카운트인 클릭은 납니다. 카운트인이 켜져 있으면 버튼에 마디 수가 작게 표시됩니다. |

설정(켜짐, 소리, 음량, 강세, 녹음 전용, 카운트인)은 프로젝트가 아니라 **앱 환경설정**으로 이 컴퓨터/브라우저에 저장됩니다(`garak-ieum:metronome:v1`). 저장값이 일부 빠지거나 잘못되어 있으면 그 항목만 기본값으로 돌아갑니다.

## 소리

| 이름 | 첫 박 | 묶음 첫 박(겹박자) | 나머지 박 |
| --- | --- | --- | --- |
| 전자음 | 높은 삐 | 중간 삐 | 삐 |
| 우드블록 | 높은 톡 | 톡 | 톡 |
| 림 클릭 | 강한 딱 | 딱 | 딱 |
| 카우벨 | 강한 땡 | 땡 | 짧은 땡 |
| 장구 | 덩(궁편+채편) | 쿵(궁편) | 덕(채편) |
| 소리북 | 합(궁+딱) | 궁(손바닥으로 가죽) | 딱(북채로 통) |
| 박 | 짝(여러 판) | 짝 | 작은 짝 |
| 꽹과리 | 갱(열린 소리) | 개(짧게) | 짓(손으로 막은 소리) |
| 목탁 | 강한 똑 | 똑 | 똑 |

모든 소리는 샘플 없이 코드로 합성합니다([`src/audio/metronomeSounds.ts`](../src/audio/metronomeSounds.ts)). 가죽(원형 막의 배음 비율과 음높이 하강), 나무·놋쇠(감쇠하는 비조화 배음), 채·손이 닿는 순간(짧게 걸러 낸 잡음)을 더한 모달 합성이라 라이선스 문제가 없습니다. 레벨별 소리는 저음을 덜 세는 간이 가중 RMS로 크기를 맞춘 뒤 첫 박 1.0, 묶음 첫 박 0.78, 나머지 0.62 비율로 둡니다. 장구 '기덕' 같은 꾸밈음은 첫 타격이 박보다 앞서야 해서 넣지 않았고, 나머지 박은 채편 '덕' 한 번입니다.

## 박자와 타이밍

- 박 단위는 박자표의 분모입니다. 4/4는 4분음표, 2/2는 2분음표, 6/8은 8분음표마다 클릭합니다.
- 분자가 3의 배수이고 3보다 큰 /8·/16 박자(6/8, 9/8, 12/8, 6/16 …)는 겹박자로 보고 세 박씩 묶습니다. 7/8 같은 나머지 박자는 마디 첫 박만 강세를 줍니다.
- 마디는 프로젝트 0박에서 시작합니다. 템포 맵([TEMPO_MAP.md](TEMPO_MAP.md))이 있으면 클릭은 박 격자 그대로, 시각만 계단·램프를 정확히 따릅니다. 카운트인은 재생 시작 위치의 템포로 고르게 칩니다. 템포·박자표를 바꾸면 다음 클릭부터 바로 따릅니다.
- 곡 중간에 박자가 바뀌면([METER_MAP.md](METER_MAP.md)) 각 박자의 펄스가 그 첫 마디선에서 다시 시작합니다. 마디마다 첫 박이 강세이고 겹박자 묶음도 마디 안에서 유지됩니다. 카운트인은 재생 시작 위치의 박자로 셉니다. 웹(`meterClicksInRange`)과 네이티브(`metronome::meterClicks`)가 같은 규칙입니다.
- 루프 구간에서는 루프 끝에서 시작점으로 넘어가며, 시작점 박은 한 번만 울립니다.

### 웹(Web Audio)

엔진의 미리 예약 스케줄러(25 ms마다 120 ms 앞까지)가 재생 구간을 나눌 때 같은 구간의 클릭을 `AudioBufferSourceNode.start(시각)`으로 오디오 시계에 예약합니다. 타이머로 소리를 내지 않습니다. 클릭 버스는 프로젝트 그래프 밖에서 `destination`으로 바로 갑니다. 그래서 마스터 볼륨·이펙트·미터, MediaRecorder 입력, `OfflineAudioContext` 내보내기와 섞이지 않습니다. 정지·탐색·템포 변경 때에는 아직 울리지 않은 클릭을 취소합니다. 카운트인은 재생 기준 시각을 카운트인 길이만큼 늦추고, `play()`는 다운비트 시각에 돌아와 녹음이 음악과 함께 시작합니다.

### 데스크톱(네이티브 엔진)

UI가 합성한 세 레벨 PCM을 `metronome.set { enabled, volume, sampleRate, strokes? }`로 호스트에 한 번 보냅니다(소리·강세·샘플레이트가 바뀔 때만 `strokes` 포함). 호스트는 장치를 다시 구성해도 설정을 유지합니다. 클릭은 `RenderEngine::render` 콜백 안에서 마스터 처리와 미터 다음에 정확한 프로젝트 프레임(`round(pulse × 프레임/박)`)에 더해집니다([`native/src/metronome.hpp`](../native/src/metronome.hpp)). 콜백에서는 할당하지 않습니다. 오프라인 인스턴스(WAV 내보내기)는 클릭을 만들지 않습니다.

`transport.play { countInFrames }`이면 엔진이 위치를 멈춘 채 카운트인 클릭을 내고, 끝난 바로 다음 프레임에 재생을 시작합니다. 카운트인 중에 시작한 녹음은 캡처를 기다렸다가 그 프레임부터 기록하며, 테이크 시작 위치는 재생 위치 그대로입니다.
