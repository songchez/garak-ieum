# 단축키

가락이음은 로직 프로(Logic Pro) 기본 키 명령을 기준으로 단축키를 정했습니다. macOS에서는 `⌘`·`⌥`, Windows·Linux에서는 `Ctrl`·`Alt`를 씁니다. 키 판정은 [`src/core/input.ts`](../src/core/input.ts)의 `SHORTCUT_BINDINGS`가 단일 기준이며, 도움말 창은 같은 파일의 `SHORTCUT_TABLE`·`shortcutLabel()`을 사용합니다. 이 문서의 표도 그 데이터와 일치해야 합니다.

- **연결 상태**: `연결됨`은 작성 시점에 화면에서 동작하는 키, `예정`은 키 판정만 준비되어 있고 엔진·UI 연결이 남은 키입니다. 실제 연결 여부는 [구현 상태](IMPLEMENTATION_STATUS.md)를 기준으로 합니다.
- **범위**: 키보드 포커스가 있는 편집 영역입니다. `타임라인`·`피아노롤`은 각 편집기 안, `작업 공간`은 그 밖의 앱 화면입니다. 믹서와 디바이스 랙도 클릭하면 키 포커스를 받으며, 작업 공간 키(재생·실행 취소·확대 등)를 그대로 씁니다. 입력 필드·버튼 같은 네이티브 컨트롤, 대화상자 안에서는 어떤 단축키도 실행하지 않습니다.
- **로직 프로 기본값**은 참고용입니다. 동작이 다른 키는 괄호로 표시했습니다.

## 키 판정 규칙

- `⌘`/`Ctrl` 조합은 두 키 중 **정확히 하나**만 눌렀을 때 인정합니다. macOS에서 `Ctrl`, Windows에서 `⌘`(Win 키)를 눌러도 같은 명령으로 처리합니다. `⌥`/`Alt`가 함께 눌리면 `⌥⌘N`(새 트랙)을 제외하고 무시합니다.
- 수식키 없는 한 글자 키(`L` `M` `S` `C` `R` `K` `Z` `Q` `;` `,` `.`)는 수식키가 하나라도 있으면 실행하지 않습니다. `⇧`+글자 명령은 `⇧`만 허용합니다.
- 글자 키는 물리 키 위치(`event.code`)로 판정하므로 한글 자판에서도 동작합니다. 한글 조합 중 입력, `AltGr` 문자 입력, 데드 키, 자동 반복(재생·삭제·저장 등)은 무시합니다.
- `Delete`와 `Backspace`는 같은 키로 취급합니다.
- `Ctrl+Y`(다시 실행)는 Windows·Linux에서만 인정합니다.
- 브라우저가 예약한 키가 있습니다. `⌘T`/`Ctrl+T`(새 탭), `Ctrl+N`(새 창)은 전체 화면이 아니면 브라우저가 먼저 가져갈 수 있어 분할은 `⌘E`/`Ctrl+E`, 새 트랙은 `⌥⌘N`/`Ctrl+Alt+N`을 함께 둡니다. `Alt+←/→`(뒤로/앞으로), `⌘[`/`⌘]`는 편집 영역에 포커스가 있을 때만 가로챕니다.

## 확대/축소

로직 프로처럼 **키 포커스가 있는 영역**만 확대/축소합니다. 키 포커스는 마지막으로 클릭한 영역(어레인지먼트·피아노롤·믹서·디바이스 랙)이 가지며, 아무 영역도 포커스가 없으면 어레인지먼트에 적용합니다. 입력 필드·슬라이더·노브에 포커스가 있으면 그 컨트롤이 방향키를 씁니다. 각 영역 제목줄(믹서·디바이스는 하단 편집기 도구줄)의 `↔ − +`, `↕ − +`, 맞춤 버튼도 같은 명령이며, 누른 뒤에도 키 포커스는 그 영역에 남습니다. 배율은 영역별로 브라우저 `localStorage`(`garak-ieum:zoom`)에 기억합니다.

| 입력 | macOS | Windows/Linux | 동작 |
| --- | --- | --- | --- |
| 가로 확대 / 축소 | `⌘→` / `⌘←` | `Ctrl+→` / `Ctrl+←` | 한 번에 1.25배 |
| 세로 확대 / 축소 | `⌘↓` / `⌘↑` | `Ctrl+↓` / `Ctrl+↑` | 한 번에 1.2배 (`⌘↓`가 더 크게) |
| 맞춰 보기 | `Z` | `Z` | 영역별 맞춤 (아래 표) |
| 포인터 기준 가로 확대/축소 | `⌘`+휠, 트랙패드 핀치 | `Ctrl`+휠, 트랙패드 핀치 | 포인터 아래 위치를 고정 |
| 포인터 기준 세로 확대/축소 | `⇧⌘`+휠 또는 `⌥`+휠 | `Ctrl+Shift`+휠 또는 `Alt`+휠 | 포인터 아래 트랙·음높이를 고정 |
| 스크롤 | 휠 / `⇧`+휠 | 휠 / `Shift`+휠 | 세로 / 가로 스크롤 (브라우저 기본) |

## 드래그 수식키

`dragModifiers()`가 판정하며 모든 플랫폼에서 같습니다. 로직 프로와 같이 `⌘`는 드래그 수식키로 쓰지 않습니다. 판정 함수만 준비되어 있고 타임라인·피아노롤 드래그 연결은 예정입니다.

| 동작 | macOS | Windows/Linux | 로직 프로 기본값 |
| --- | --- | --- | --- |
| 복사하며 드래그 | `⌥` + 드래그 | `Alt` + 드래그 | `⌥` + 드래그 |
| 세밀하게 이동(스냅 간격의 1/4) | `⌃` + 드래그 | `Ctrl` + 드래그 | `⌃` + 드래그 (한 분할 단위) |
| 스냅 무시 | `⌃⇧` + 드래그 | `Ctrl+Shift` + 드래그 | `⌃⇧` + 드래그 (틱 단위) |
| 한 방향으로 고정 | `⇧` + 드래그 | `Shift` + 드래그 | `⇧` + 드래그 |

macOS에서 `⌃`를 누른 채 클릭하면 브라우저가 상황 메뉴를 엽니다. 그래서 세밀 이동·스냅 무시는 드래그를 시작한 **뒤에** `⌃`를 누르는 방식으로 설계했습니다. 화면 연결 시 수식키는 포인터가 움직일 때마다 다시 읽어야 합니다.
