# 가락이음 0.3.4 개발 프리뷰

재생 위치를 옮길 때의 소리를 정리한 작은 업데이트입니다. 프로젝트 형식은 그대로(19)입니다.

## 고친 문제

- **재생 위치를 끌 때 나던 소리:** 재생 중에 눈금자에서 재생 위치를 끌면 마우스가 지나가는 자리마다 짧은 소리가 끊기듯 났습니다. 이제 끄는 동안에는 재생선만 움직이고, 손을 뗀 위치에서 한 번만 이어서 재생합니다. 끌기가 취소되면 위치는 그대로입니다.
- 눈금자를 클릭해 바로 옮기는 동작과, 멈춘 상태에서 끄는 동작은 예전과 같습니다.

## 알아 둘 점

- 프로젝트 형식은 바뀌지 않았습니다(19). 0.3.1–0.3.4는 서로의 프로젝트를 그대로 엽니다.
- 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트, 네이티브 엔진 테스트, 기준 파일 대조 테스트, 브라우저 엔진 smoke, 설치 검사와 설치 앱 smoke를 통과한 뒤 함께 게시합니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
