# 가락이음 0.1.3 개발 프리뷰

상단 헤더와 메뉴를 하나로 정리하고, VST3를 악기·디바이스와 같은 자리에서 다루도록 바꾼 업데이트입니다. 피치 편집기는 별도 창으로 열립니다.

## 주요 변경

- **하나의 메뉴 막대:** `파일 · 편집 · 기능 · 보기 · 도움말`을 제목 표시줄에 모았습니다. 로고 옆의 앱 메뉴 버튼과 로고 메뉴는 없앴고, 새 프로젝트·프로젝트 열기·목록·저장·내보내기·설정은 **파일**에서 엽니다. 화면 배율과 전체 화면은 **보기**로 합쳤습니다.
- **정리한 컨트롤 막대:** 왼쪽에 라이브러리·인스펙터 토글과 프로젝트 이름, 가운데 트랜스포트, 오른쪽에 브라우저 토글·AI 연결·설정·내보내기를 둡니다. 헤더의 기와 장식은 제거했습니다.
- **VST3는 악기이거나 디바이스:** VST3 이펙트가 내장 이펙트와 같은 디바이스 체인에 카드로 놓이며, 순서를 자유롭게 섞을 수 있습니다. 카드에서 플러그인 창 열기·상태 저장·파라미터·바이패스·이동을 다룹니다. VST3 악기는 악기 선택 목록과 라이브러리의 **VST3** 분류에서 고르며, 바로 새 트랙으로 만들 수 있습니다.
- **플러그인 등록 위치:** VST3 파일은 **설정 › 플러그인**에서 등록합니다. 다른 컴퓨터에서 연 프로젝트는 같은 플러그인을 등록한 뒤 카드의 **설치본 연결**로 저장한 상태를 이어서 사용합니다.
- **피치 편집 창:** 피치 편집기가 하단 탭 대신 떠 있는 창으로 열립니다. 창을 연 채로 재생해 들을 수 있고, 제목 표시줄을 끌어 옮기거나 더블 클릭해 최대화합니다.

## 프로젝트 파일 호환

프로젝트 스키마가 **7**로 올라갑니다. 이전 버전에서 만든 프로젝트는 그대로 열리며, 따로 있던 VST3 이펙트는 기존 처리 순서대로 디바이스 체인 끝에 옮겨집니다. **0.1.3에서 저장한 프로젝트는 0.1.2 이하에서 열 수 없습니다.**

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트·설치 검사·설치 앱의 메뉴 막대/창 배율/VST3 등록 위치/WAVE/MIDI smoke를 통과한 뒤 함께 게시합니다. 명시적인 테스트 클록을 사용하는 검사는 물리 오디오 장치의 재생·왕복 지연 측정과 구분하며, 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
