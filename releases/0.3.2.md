# 가락이음 0.3.2 개발 프리뷰

가락이음의 오디오 엔진 전체를 **Rust로 만든 통합 엔진 하나**로 바꾼 업데이트입니다. 트랙 재생, 내장 악기, 시김새(이펙트), 기타 앰프, 센드·리턴과 믹스를 데스크톱과 웹이 같은 엔진으로 처리합니다. 소리는 이전과 같고, 무거운 곡은 더 가볍게 돕니다. 프로젝트 형식은 그대로(19)입니다.

## 하나의 엔진

- **데스크톱:** C++은 이제 오디오 장치 연결, VST3 플러그인, IEUM WAVE 편집기, 녹음 같은 바깥 일만 맡고, 소리는 Rust 엔진이 만듭니다. VST3 악기와 이펙트도 트랙 체인의 제자리에서 그대로 돌고, 플러그인 지연 보정도 같은 규칙으로 계산합니다.
- **웹:** 같은 엔진이 브라우저의 오디오 워크릿 안에서 돕니다. 이전에는 웹과 데스크톱이 엔진을 따로 가지고 있었지만, 이제 같은 코드를 씁니다.
- **엔진으로 옮긴 것:** 오디오·악기 트랙, 내장 악기 전부(신스 5종, 드럼, 그랜드 피아노·리드 EP·가야금·해금·대금, 드럼 킷과 사물놀이, 옥구슬 EP, 한밤 106, IEUM WAVE), 시김새 전부, 기타 앰프, 센드·리턴, 트랙 입력 라우팅, 오토메이션, 템포·박자 변경, 얼린 트랙과 꼬리, 미터.

## 소리는 같습니다

- 이전 엔진과 같은 곡을 렌더링해 비교했습니다. Windows에서는 **비트 단위로 같고**, Mac에서는 차이가 −121 dBFS 이하로 들을 수 없는 수준입니다.
- 웹과 데스크톱의 Rust 엔진끼리도 같은 결과를 냅니다.

## 더 가벼워졌습니다

- **데스크톱 멀티코어:** 트랙을 여러 코어에 나눠 처리합니다. 8개 작업 스레드에서 약 2.4배 빠릅니다.
- **악기가 많은 곡:** 이전 엔진보다 Windows에서 1.2–1.3배, Mac에서 1.06배(IEUM WAVE를 뺀 곡은 1.5배) 빠릅니다.
- **기타 앰프:** Windows에서 1.1–1.6배 빠르고, Mac에서는 비슷합니다.
- **웹의 큰 곡:** 32트랙 곡이 오디오 처리 시간 예산의 31–36%만 씁니다(이전에는 3초에 수십 번 예산을 넘겼습니다).

## 웹에서도 되는 것

- 곡을 재생하는 동안 건반(키보드·MIDI)을 치면 같은 엔진에서 바로 소리가 납니다. 라이브러리 미리 듣기도 마찬가지입니다.
- 레벨 미터와 컴프레서 미터, 박자가 바뀌는 곡의 카운트인, 입력 모니터링과 녹음, 스템·얼리기 렌더도 엔진에서 처리합니다.
- 샘플 악기(피아노, 국악기, 드럼 킷)도 엔진에서 재생합니다.

## 문제가 있으면: 이전 엔진으로 되돌리기

이번 릴리스에 한해 이전 엔진을 비상용으로 남겨 두었습니다. 다음 패치에서는 지웁니다.

- **데스크톱:** 환경 변수 `GARAK_RUST_ENGINE=0`을 설정하고 앱을 띄웁니다.
- **웹:** 브라우저 콘솔에서 `localStorage.setItem('garak.rustEngine', '0')`을 실행한 뒤 새로 고칩니다. 다시 켜려면 `'1'`.

되돌렸더니 문제가 사라졌다면 설정의 **상태·진단 → 진단 복사** 내용과 함께 꼭 알려 주세요.

## 알아 둘 점

- 프로젝트 형식은 바뀌지 않았습니다(19). 0.3.1과 0.3.2는 서로의 프로젝트를 그대로 엽니다.
- 실시간 건반 입력은 오디오 블록 경계에 맞춰 들어갑니다(128프레임 기준 약 3 ms 이내). 블록 안의 정확한 위치까지 맞추는 일은 다음 단계에서 합니다.
- 웹은 파형 표시와 편집 도구를 위해 오디오 파일을 메인 화면 쪽에도 한 벌 더 들고 있습니다. 메모리 사용을 줄이는 일은 다음에 합니다.
- 속도 수치는 개발 환경과 CI에서 측정한 값입니다. 컴퓨터와 곡에 따라 다를 수 있습니다.
- 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트, 네이티브 엔진 테스트(새 엔진 기본·엄격 모드·이전 엔진 비상 경로 모두), Rust–C++ 패리티 테스트, 설치 검사와 설치 앱 smoke를 통과한 뒤 함께 게시합니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
