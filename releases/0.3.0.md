# 가락이음 0.3.0 개발 프리뷰

데스크톱 앱의 오디오 처리 핵심을 **Rust**로 옮기기 시작한 업데이트입니다. 첫 단계로 기타 앰프를 뺀 모든 내장 시김새(이펙트)가 데스크톱 엔진 안에서 Rust 코드로 돕니다. 소리는 그대로이고, 같은 코드를 앞으로 웹과 데스크톱이 함께 쓰게 됩니다. 프로젝트 형식은 그대로(17)입니다.

## Rust 오디오 코어

- **Rust로 처리하는 시김새 15종:** 리버브, 딜레이, 코러스, 페이저, 플랜저, 트레몰로·오토팬, 리미터, 노이즈 게이트, 테이프 새츄레이션, 비트크러셔, 유틸리티, 8밴드 EQ, 스윕 필터, 컴프레서, 드라이브. 기타 앰프(랙·캐비닛)는 아직 이전 엔진을 씁니다.
- **소리는 같습니다:** Windows에서는 이전 C++ 엔진과 **비트 단위로 같은 결과**를 냅니다. Mac에서는 차이가 −132 dBFS 이하로, 들을 수 없는 수준입니다. 파라미터 변경, 오토메이션, 템포 변경, 리버브·딜레이 꼬리, 미터와 지연 보정도 같습니다.
- **속도:** Windows에서 대부분의 시김새가 이전과 같거나 빠릅니다(리버브 1.2–2.8배, 페이저 1.1–1.4배, 테이프 1.14배). Mac에서는 리미터와 딜레이가 이전보다 10–20% 정도 CPU를 더 쓸 수 있습니다.
- **이전 엔진으로 되돌리기:** 문제가 의심되면 환경 변수 `GARAK_RUST_EFFECTS=none`을 설정하고 앱을 띄우면 이전 C++ 처리로 돌아갑니다. 이때도 차이가 있으면 Rust 문제가 아니라는 뜻이니 함께 알려 주세요.

## 알아 둘 점

- 프로젝트 형식은 바뀌지 않았습니다. 0.2.x와 0.3.0은 서로의 프로젝트를 그대로 엽니다.
- 브라우저(웹) 버전은 아직 이전 처리 경로를 씁니다. 웹의 Rust(WebAssembly) 처리는 다음 단계에서 켭니다.
- 속도 수치는 개발 환경과 CI에서 측정한 값입니다. 컴퓨터와 곡에 따라 다를 수 있습니다.
- 소리나 CPU 사용량이 이전 버전과 다르게 느껴지면 설정의 **상태·진단 → 진단 복사** 내용과 함께 알려 주세요.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트·네이티브 엔진 테스트(Rust 시김새 포함)·Rust–C++ 패리티 테스트·설치 검사·설치 앱 smoke를 통과한 뒤 함께 게시합니다. 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
