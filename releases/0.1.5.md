# 가락이음 0.1.5 개발 프리뷰

프로젝트 저장·내보내기와 앱 닫기의 문제를 고친 업데이트입니다.

## 수정

- **프로젝트 내보내기 실패:** 가져온 오디오의 원본 파일이 옮겨지거나 바뀌면(클라우드 동기화 폴더 포함) 자동 저장과 `.garak` 내보내기가 "The requested file could not be read" 오류로 실패하던 문제를 고쳤습니다. 이제 오디오를 가져올 때 사본을 앱 안에 보관하므로 원본 파일의 위치와 상관없이 저장됩니다. 이미 읽을 수 없게 된 원본은 파일 이름과 함께 안내합니다.
- **저장하지 못하면 닫히지 않던 문제:** 닫거나 다른 프로젝트로 이동하기 직전의 저장이 실패하면, 이제 **파일로 저장하고 닫기 / 저장하지 않고 닫기 / 취소** 중에서 고를 수 있습니다. 저장하지 않고 닫으면 마지막으로 자동 저장된 상태가 남습니다. 평소처럼 저장이 되면 묻지 않고 바로 닫힙니다.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트·설치 검사·설치 앱 smoke를 통과한 뒤 함께 게시합니다. 명시적인 테스트 클록을 사용하는 검사는 물리 오디오 장치의 재생·왕복 지연 측정과 구분하며, 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
