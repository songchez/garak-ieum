# 가락이음 0.1.2 개발 프리뷰

이음웨이브의 네이티브 재생, MIDI 파일 가져오기와 데스크톱 제목 표시줄을 개선한 업데이트입니다.

## 주요 수정

- **IEUM WAVE 네이티브 연결:** 이음웨이브를 공통 오디오 엔진에 연결했습니다. Windows 기본 WASAPI 출력, ASIO, macOS Core Audio에서 같은 DSP로 건반 미리 듣기·타임라인 재생·WAV 출력을 처리합니다. 편집 중 누른 음을 유지하며, 새 파형은 오디오 스레드 밖에서 준비합니다.
- **MIDI 파일 가져오기:** `.mid`·`.midi`·`.smf` 파일을 선택하거나 타임라인에 놓으면 편집 가능한 MIDI 트랙·음표로 가져옵니다. Type 0/1 PPQ, 여러 트랙·채널, running status, velocity와 서스테인을 지원합니다. 단일 파트를 기존 이음웨이브 레인에 놓으면 그 음색을 유지합니다.
- **창 제목 표시줄과 메뉴:** 프로젝트 이름과 앱 테마를 반영하는 제목 표시줄을 추가하고, 트랙 위에 있던 편집·기능·보기 메뉴를 상단 헤더로 옮겼습니다. Windows 창 버튼과 macOS 기본 창 버튼, 창 드래그, 메뉴 단축키, 종료 전 저장 처리를 유지합니다.

## MIDI 가져오기 동작

기존 프로젝트의 템포·박자는 유지합니다. 트랙과 마커가 없는 새 프로젝트의 시작 위치에 MIDI 파일 하나를 가져올 때만 초기 템포·박자를 적용합니다. 여러 파일의 가져오기는 한 번에 적용되며, 손상된 파일이 포함되면 기존 작업을 변경하지 않습니다. 실행 취소·다시 실행을 지원합니다.

General MIDI 음색은 기본 건반·드럼에 연결되며 라이브러리에서 바꿀 수 있습니다. 곡 중간의 템포·박자 변경, 피치 벤드, 애프터터치와 대부분의 CC 자동화는 아직 가져오지 않으며 파일에 해당 정보가 있으면 안내합니다. Type 2와 SMPTE 기반 파일은 Type 0/1 PPQ로 다시 저장해 주세요.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트·실제 네이티브 DSP/IPC 검사·설치 검사·설치 앱의 WAVE/MIDI/창 조작 smoke를 통과한 뒤 함께 게시합니다. 명시적인 테스트 클록을 사용하는 검사는 물리 오디오 장치의 재생·왕복 지연 측정과 구분합니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
