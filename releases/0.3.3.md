# 가락이음 0.3.3 개발 프리뷰

0.3.2에서 기본이 된 Rust 통합 엔진만 남기고 이전 엔진을 모두 정리한 업데이트입니다. 남은 숙제였던 실시간 건반 타이밍, 웹 메모리, 웹 IEUM WAVE도 함께 해결했고, 데스크톱에도 분석기와 튜너 표시가 생겼습니다. 프로젝트 형식은 그대로(19)입니다.

## 이전 엔진 정리

- **데스크톱:** 이전 C++ 트랙 처리, C++ 시김새·기타 앰프, C++ IEUM WAVE 신스를 지웠습니다. 메트로놈과 마스터 버스도 Rust 엔진에서 처리합니다. 이제 C++은 오디오 장치, VST3 플러그인, 녹음만 맡습니다.
- **웹:** 이전 Web Audio 엔진과 TS 시김새를 지웠습니다. 모든 소리는 Rust 엔진이 만듭니다.
- 0.3.2의 비상 스위치(`GARAK_RUST_ENGINE=0`, `localStorage garak.rustEngine=0` 등)는 없어졌습니다.
- 브라우저가 엔진을 불러오지 못하면(AudioWorklet이나 WebAssembly 미지원 등) 이제 조용히 다른 경로로 넘어가지 않고 안내 메시지를 띄웁니다.
- 코드 약 19,700줄을 지우고 7,900줄을 새로 써서, 전체로 약 11,800줄 줄었습니다.

## 소리는 그대로입니다

- 이전 엔진을 지우기 전에 그 출력을 기준 파일로 저장해 두고, 새 엔진이 같은 소리를 내는지 매번 검사합니다(시김새·기타 앰프 1,113가지, 악기, 엔진, IEUM WAVE).
- Windows에서는 기준과 **비트 단위로 같고**, Mac에서는 차이가 −138 dBFS 이하로 들을 수 없는 수준입니다.

## 실시간 건반이 정확해졌습니다

- 건반, 미리 듣기, 컨트롤러, 피치 벤드, 애프터터치가 오디오 블록 단위가 아니라 **누른 순간의 정확한 샘플 위치**에 들어갑니다. VST3 플러그인에도 같은 위치가 전달됩니다.
- 웹에서도 피치 벤드, 애프터터치, 프로그램 체인지가 연주 중에 바로 소리에 반영됩니다.

## 웹이 가벼워졌습니다

- 화면 쪽에서 오디오 원본을 한 벌 더 들고 있지 않고, 파형 미리보기 데이터만 둡니다. 편집 도구가 원본이 필요할 때만 불러옵니다.
- 5분짜리 스테레오 오디오 4개가 든 곡에서 메모리가 509 MB에서 쉬고 있을 때 약 58 MB로 줄었습니다.
- 데스크톱도 앱 화면과 오디오 엔진이 같은 소리를 두 벌 들고 있지 않습니다.
- 오래 안 쓴 긴 파일을 피치 편집 같은 도구로 처음 열 때는 원본을 다시 불러오느라 잠깐 늦을 수 있습니다.

## 새로 되는 것

- **웹에서 IEUM WAVE:** 브라우저에서도 IEUM WAVE를 쓸 수 있습니다. 프리셋 바꾸기와 편집기 건반도 됩니다.
- **데스크톱 분석기·튜너:** EQ·필터 화면의 스펙트럼 분석기, 기타 앰프 튜너 표시, 유틸리티 스테레오 스코프가 데스크톱에서도 움직입니다. 편집 화면을 연 장치만 신호를 보내므로 평소 부담은 없습니다.

## 고친 문제

- **편집이 새로 고침 후 사라지던 문제:** 값을 계속 바꾸는 동안 자동 저장이 미뤄져, 그 사이 페이지를 새로 고치거나 닫으면 마지막 편집이 사라질 수 있었습니다(기타 앰프 마이크, EQ, 시김새, 악기 등 모든 편집기). 이제 편집 중에도 5초 안에 저장하고, 창을 닫거나 숨기거나 Ctrl+S를 누르면 바로 저장합니다.
- **웹 기타 앰프:** 웹에서 기타 앰프를 넣으면 엔진이 메모리 부족으로 멈추던 문제를 고쳤습니다. 0.3.2에서는 이전 엔진으로 몰래 넘어가 드러나지 않았습니다.

## 알아 둘 점

- 프로젝트 형식은 바뀌지 않았습니다(19). 0.3.1–0.3.3은 서로의 프로젝트를 그대로 엽니다.
- 이전 엔진으로 되돌리는 방법은 더 이상 없습니다. 소리나 동작이 이상하면 설정의 **상태·진단 → 진단 복사** 내용과 함께 알려 주세요.
- 수치는 개발 환경과 CI에서 측정한 값이며 컴퓨터와 곡에 따라 다를 수 있습니다.
- 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트, 네이티브 엔진 테스트, 기준 파일 대조 테스트, 브라우저 엔진 smoke, 설치 검사와 설치 앱 smoke를 통과한 뒤 함께 게시합니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
