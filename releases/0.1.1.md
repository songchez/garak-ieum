# 가락이음 0.1.1 개발 프리뷰

가락이음의 첫 공개 설치형 개발 프리뷰입니다.

## 주요 내용

- Windows 64비트 설치 마법사와 Apple Silicon Mac용 DMG를 제공합니다.
- 네이티브 오디오 엔진과 IEUM WAVE 웨이브테이블 신디사이저·편집기를 포함합니다.
- 국악기와 전자음악 편곡, 피아노롤·리전 편집, 프로젝트 저장과 오디오 내보내기를 지원합니다.

## 배포 검증

- Windows와 macOS 설치본을 같은 소스 커밋에서 빌드합니다.
- 단위 테스트, 네이티브 통합 테스트, 설치 및 설치된 앱의 실행 검증을 모두 통과한 뒤 두 플랫폼을 함께 게시합니다.
- 설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
