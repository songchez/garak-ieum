# 가락이음 0.1.6 개발 프리뷰

오디오 인터페이스 연결과 녹음의 핵심을 다시 만든 업데이트입니다. Logic Pro·Ableton Live·Cubase의 장치 처리 방식을 참고했습니다.

## 오디오 인터페이스 연결

- **장치 정보 자동 읽기:** 드라이버를 고르면 채널 이름과 개수, 쓸 수 있는 버퍼 크기와 샘플레이트를 읽어 옵니다. 버퍼는 허용되는 값만 고를 수 있고 기본값은 드라이버 권장값입니다. 버퍼를 드라이버가 고정하면 **제어판 열기**로 안내합니다.
- **자동 재연결:** 케이블이 빠졌다 다시 꽂히거나 드라이버 제어판에서 설정을 바꾸면 같은 설정으로 다시 연결합니다.
- **원인별 안내:** 연결에 실패하면 "다른 앱이 사용 중", "지원하지 않는 샘플레이트"처럼 이유와 해결 버튼을 보여 줍니다. 샘플레이트가 맞지 않으면 장치를 맞추거나 프로젝트 레이트를 바꾸는 선택지를 줍니다.
- **입출력 채널:** 쓸 입력 채널을 켜고, 스테레오 쌍과 채널 이름을 정할 수 있습니다.
- **그 밖에:** ASIO 클럭 소스와 하드웨어 직접 모니터링 제어, 다른 앱으로 전환할 때 인터페이스를 양보하는 **백그라운드에서 드라이버 해제** 옵션을 추가했습니다.

## 녹음

- **트랙별 입력:** 트랙마다 입력을 고릅니다(예: 1번 트랙 마이크, 2번 트랙 기타).
- **동시 녹음:** 녹음 대기한 오디오 트랙을 여러 개 한 번에 녹음하고, 실행 취소 한 번으로 함께 되돌립니다.
- **모니터 켬/자동/끔:** 자동은 녹음 대기 중에 입력을 들려주고, 녹음 없이 재생만 할 때는 끕니다.
- **입력 다시 연결:** 다른 컴퓨터에서 연 프로젝트의 입력이 없으면 같은 이름의 채널을 찾고, 못 찾으면 다시 연결할 창을 띄웁니다.
- **지연 실측:** 출력을 입력으로 연결한 케이블로 실제 왕복 지연을 재고 녹음 위치 보정에 적용합니다. 보정 단위가 프레임으로 바뀌었습니다.

## 성능

- 트랙 처리를 여러 CPU 코어로 나눕니다. 결과는 한 코어로 처리할 때와 완전히 같습니다.
- 처리가 밀리면 알림을 띄웁니다.
- 녹음하지 않는 트랙을 미리 계산하는 **재생 트랙 미리 처리**를 추가했습니다. 실제 장비 검증 전이라 기본은 꺼져 있습니다.

## 알아 둘 점

- 기존 프로젝트에서 모니터(I)가 꺼져 있던 트랙은 **자동**이 되어, 녹음 대기만 켜도 입력이 들립니다.
- 프로젝트 형식이 8로 올라갑니다. **0.1.6에서 저장한 프로젝트는 0.1.5 이하에서 열 수 없습니다.**
- 실제 ASIO 인터페이스와 Mac Core Audio 장치에서의 동작은 아직 충분히 검증하지 못했습니다. 문제가 있으면 설정의 **상태·진단 → 진단 복사** 내용과 함께 알려 주세요.

## 배포 검증

Windows와 Apple Silicon Mac 설치본은 같은 소스 커밋에서 빌드하며, 단위 테스트·네이티브 엔진 테스트·설치 검사·설치 앱 smoke를 통과한 뒤 함께 게시합니다. 명시적인 테스트 클록을 사용하는 검사는 물리 오디오 장치의 재생·왕복 지연 측정과 구분하며, 타사 VST3 플러그인 각각의 호환성을 보증하지는 않습니다.

설치본에 대응하는 소스 ZIP, 라이선스·외부 구성요소 고지와 SHA-256 체크섬을 함께 제공합니다.
